## 0. Постановка и проверка оператора

Класс универсальности: семейства f_a(x) = 1 − a|x|^d, d > 1. Оператор удвоения на
нормированных функциях (f(0) = 1) в том виде, как он реализован во всех наших кодах:

  **T(f)(x) = −α_f · f(f(x/α_f)),  α_f = −1/f(1).**

Неподвижная точка g = Tg: g(x) = −α·g(g(x/α)), g(0) = 1, g(1) = −1/α; в
t-представлении x ↦ t = |x|^d: g(x) = G(t), G(t) = −α·G(ω(t)), где

  τ = t/α^d,  U = G(τ),  ω = |U|^d,  K(t) = G(t) − d·t·G′(t).

**Проверка, чему равна DT** (выполнена явно, до каждого члена): для семейства
f_ε = g + εφ, φ(x) = Φ(|x|^d), Φ(0) = 0, разложение T(f_ε) = g + ε·DT[φ] + O(ε²)
с учётом вариации α_{f_ε} = −1/f_ε(1) = α(1 + εαΦ(1) + …) даёт в точности формулу
из всех наших кодов:

  (DTΦ)(t) = −(Φ(1)/G(1))·K(t) − α·Φ(ω(t)) − α·d·sign(U)·|U|^{d−1}·G′(ω)·Φ(τ).   (0)

Первый член — вклад вариации α_f (калибровочный, «gauge»), второй — композиция с
внутренней точкой, третий — перенос аргумента. Полезная перезапись третьего члена
через дифференцированное уравнение неподвижной точки
G′(t) = −α^{1−d}·d·sign(U)·|U|^{d−1}·G′(ω)·G′(τ):

  (DTΦ)(t) = −(Φ(1)/G(1))·K(t) + (JΦ)(t) + (SΦ)(t),
  (JΦ)(t) := −α·Φ(ω(t)),   (SΦ)(t) := m(t)·Φ(τ),   m(t) := α^d·G′(t)/G′(τ).   (0′)

## 1. Формулировка

Пусть d > 1, G — неподвижная точка (0), k ≥ 1 целое. Для вещественного y и
вещественного p положим [y]^p := sign(y)·|y|^p («нечётная ветвь» степени; при
нечётном целом p она совпадает с обычной степенью y^p). Определим

  **Φ_k(t) := d·t^{k+1}·G′(t) − [G(t)]^{dk+1} + G(t) − d·t·G′(t)
            = d·t·(t^k − 1)·G′(t) + (1 − [G(t)]^{dk})·G(t).**

**Лемма (точная, поточечная).** Для всякого d > 1 и всякого целого k ≥ 1 функция Φ_k
удовлетворяет тождеству

  **DT[Φ_k] = α^{−dk}·Φ_k**

на всей области определения оператора (как тождество вещественных функций; все
степени понимаются по нечётной ветви, а |U|^d — как в самой DT).

**Лемма′ (аналитическая).** Φ_k принадлежит классу аналитических в t функций
(т.е. разложима в ряд по целым степеням t, на котором построена коллокация и
спектральные расчёты) **тогда и только тогда, когда dk — чётное целое**. Именно:

- d чётное целое ⇒ башня α^{−dk} присутствует в аналитическом спектре целиком (k = 1, 2, 3, …);
- d нечётное целое ⇒ только чётные k (α^{−2d}, α^{−4d}, …); при нечётных k кандидат
  имеет излом в нуле G и выпадает из аналитического класса;
- d = p/q рациональное (несократимая дробь) ⇒ только k, кратные минимальному k₀ с
  p·k₀/q ∈ 2ℤ (например, d = 5/2: k₀ = 4, т.е. α^{−10}, α^{−20}, …; d = 12/5: k₀ = 5);
- d иррациональное ⇒ аналитических членов башни нет ни при каком k.

## 2. Доказательство

**Шаг 1 (ядро S — чистая однородность).** Для Φ_A,k(t) := d·t^{k+1}·G′(t):

  S[Φ_A,k](t) = m(t)·d·τ^{k+1}·G′(τ) = α^d·(G′(t)/G′(τ))·d·(t/α^d)^{k+1}·G′(τ)
              = **α^{−dk}·d·t^{k+1}·G′(t)**.

Множитель G′(τ) сокращается точно; никаких свойств G, кроме дифференцируемости, не
нужно. Собственное значение возникает как вес одночлена t^{k+1} при рескейлинге
аргумента t ↦ t/α^d.

**Шаг 2 (ядро J — полулинейность G∘ω).** Из уравнения неподвижной точки G(ω(t)) = −G(t)/α
и нечётности ветви [−y]^p = −[y]^p·… (точнее [−G/α]^q = −[G]^q/α^q):

  J[[G]^{dk+1}](t) = −α·[G(ω(t))]^{dk+1} = −α·(−[G(t)]^{dk+1}/α^{dk+1}) = **α^{−dk}·[G(t)]^{dk+1}**.

Знак «+» здесь — в точности место, где нужна чётность произведения dk в аналитической
версии: при целом нечётном dk+1 ветвь совпадает с обычной степенью и знак
(−1)^{dk+1} = −1 даёт «+»; при целом чётном dk+1 аналитическая (обычная) степень дала
бы знак «−» — см. п. 4.

**Шаг 3 (перекрёстное тождество — ключ всего).** Покажем, что перекрёстные члены
J[Φ_A,k] и S[[G]^{dk+1}] **равны друг другу**. С одной стороны

  J[Φ_A,k](t) = −α·d·ω^{k+1}·G′(ω(t)) = −α·d·|U|^{d(k+1)}·G′(ω).

С другой стороны, дифференцируя G(t) = −α·G(ω(t)) и раскатывая ω′(t) =
d·sign(U)·|U|^{d−1}·G′(τ)/α^d:

  G′(t) = −α^{1−d}·d·sign(U)·|U|^{d−1}·G′(ω)·G′(τ)  ⇒  m(t) = −α·d·sign(U)·|U|^{d−1}·G′(ω),

откуда

  S[[G]^{dk+1}](t) = m(t)·[U]^{dk+1} = −α·d·sign(U)·|U|^{d−1}·G′(ω)·sign(U)·|U|^{dk+1}
                   = −α·d·|U|^{d+dk}·G′(ω) = **−α·d·ω^{k+1}·G′(ω) = J[Φ_A,k](t)**.

(sign(U) входит дважды и сокращается — поэтому тождество держится на нечётной ветви
при любом d.) В частности, при k = 0: S[G] = J[Φ_A,0], а S[Φ_A,0] = Φ_A,0 = d·t·G′(t)
(шаг 1 при k = 0), J[G] = G (шаг 2 при q = 1).

**Шаг 4 (калибровочная компенсация).** Пусть μ := α^{−dk}. Соберём DT на линейной
комбинации Φ_k = Φ_A,k − [G]^{dk+1} + G − Φ_A,0, пользуясь линейностью и шагами 1–3
(перекрёстные члены в комбинации взаимно уничтожаются попарно: J[Φ_A,k]−S[[G]^{dk+1}] = 0
и S[G]−J[Φ_A,0] = 0):

  DT[Φ_k] = −(Φ_k(1)/G(1))·K + μ·Φ_A,k + J[Φ_A,k] − μ·[G]^{dk+1} − S[[G]^{dk+1}]
            + G + S[G] − Φ_A,0 − J[Φ_A,0]
          = −(Φ_k(1)/G(1))·K + μ·(Φ_A,k − [G]^{dk+1}) + (G − Φ_A,0).

Осталось значение в точке нормировки t = 1. Так как Φ_A,k(1) = d·G′(1) = Φ_A,0(1) —
**эти два члена взаимно сокращаются** — и G(1) = −1/α, [G(1)]^{dk+1} = [−1/α]^{dk+1} =
−α^{−dk−1}:

  Φ_k(1) = Φ_A,k(1) − [G(1)]^{dk+1} + G(1) − Φ_A,0(1) = −(−α^{−dk−1}) − α^{−1}
         = (1 − α^{−dk})·G(1).

Значит калибровочный член равен −(1−μ)·K(t), и, поскольку G − Φ_A,0 = G − d·t·G′ = K:

  DT[Φ_k] = −(1−μ)·K + μ·(Φ_A,k − [G]^{dk+1}) + K = μ·(Φ_A,k − [G]^{dk+1} + K) = **μ·Φ_k**. ∎

**Замечание о механизме.** Три источника «магии»: (а) однородный вес α^{−dk} шага
рескейлинга (шаг 1); (б) полусопряжение G∘ω = −G/α, переводящее композицию в
умножение на −1/α (шаг 2); (в) точное совпадение перекрёстных членов (шаг 3) —
«диагональность» S на t-одночленах и J на G-степенях согласована друг с другом.
Калибровочная (α_f-вариационная) добавка погашается тем, что Φ_k(1) = (1−μ)·G(1),
причём вклады d·G′(1) от слоёв k и 0 сокращаются — это и есть ответ на вопрос
«куда девается α_f и нормировка».

## 3. Калибровочный смысл: семейство репараметризаций

Φ_k — касательный вектор явного однопараметрического семейства нормированных
отображений. Положим (в x-представлении, d чётное целое, k ≥ 1):

  σ_ε(x) = x·(1 + ε·(x^{dk} − 1)),   ρ_ε(y) = y·(1 + ε·(1 − y^{dk})),
  **f_ε = ρ_ε ∘ g ∘ σ_ε**.

Тогда: σ_ε(0) = 0 и σ_ε(1) = 1 (деформация координаты, неподвижная в концах);
ρ_ε(1) = 1; значит f_ε(0) = ρ_ε(g(σ_ε(0))) = ρ_ε(1) = 1 — **нормировка f(0) = 1
выполнена точно при всех ε**, и касание

  d/dε·f_ε|₀ = (x^{dk+1} − x)·g′(x) + g(x) − g(x)^{dk+1}  ↔  Φ_k(t)

— в точности кандидат леммы. Равенство DT[Φ_k] = α^{−dk}Φ_k означает
T(f_ε) = f_{ε·α^{−dk}} + O(ε²): **оператор удвоения переводит калибровочную
деформацию в себя, сжимая её параметр в α^{−dk} раз** — отсюда и собственное
значение, и его «калибровочная» природа, и кратность башни по k.

Тривиальная координатная мода K = G − d·t·G′ — это в точности слой k = 0 той же
конструкции (семейство (1+ε)·g(x/(1+ε))): она даёт DT_барe[K] = K (проверено до 1e-45
в кодах и следует из шагов 1–3 при k = 0). Для полной линеаризации (0) с учётом
калибровочного члена K — собственный вектор расширенного оператора с точным
значением **α^d** (численно: d=2 — 6.264547831…= α², d=6 — 9.997677674…= α₆⁶,
совпадение во всех знаках); K не лежит в пространстве Φ(0)=0, поэтому в проекционном
спектре кодов её нет. Башенные Φ_k при k ≥ 1 лежат в Φ(0)=0: Φ_k(0) = 0 автоматически
(и t·(t^k−1)·G′|₀ = 0, и (1−[G]^{dk})·G|₀ = 1−1 = 0).

Отдельное точное тождество (побочное): для целого d первое ненулевое разложение
уравнения неподвижной точки в нуле даёт g′(1) = −α^{d−1} (при d = 2: −α; проверено
численно: d=2 — −2.502907875…, d=4 — −4.829405415…, d=6 — −6.81160218…, все = −α^{d−1}).

## 4. Почему только при чётных d (и что именно ломается)

Поточечное тождество держится на нечётной ветви степени и верно при всех d > 1 —
численно подтверждено и при d = 2.01, 2.05, 3.0 (остаток ~1e-30 на [0,1.2]).
Ломается **не тождество, а принадлежность кандидата аналитическому классу**, в
котором определён спектральный расчёт (ряды по t, коллокация):

1. **d нечётное целое, k чётное** (dk+1 нечётное): ветвь = обычная степень,
   Φ_k — многочлен от G, G′; всё аналитично; башенный член α^{−dk} существует
   (пример: α₃^{−6} = 0.019488…, α₃^{−12} = 3.798e-4; α₅^{−10} = 0.012038; α₇^{−14} = 0.008552;
   α_{5/2}^{−10} = 5.037e-4 — все подтверждены до 1e-11…1e-20, см. п. 5).
2. **d нечётное целое, k нечётное** (dk+1 чётное): нечётная ветвь
   sign(G)·|G|^{чёт} имеет излом в нуле G (t₀ ∈ (0,1), т.к. G(1) = −1/α < 0);
   обычная же (аналитическая) степень G^{чёт} в шаге 2 даёт знак «−»: J[G^{dk+1}] =
   −α^{−dk}·G^{dk+1}, противоположный знаку шага 1, и никакая линейная комбинация
   слоёв не собирается (перекрёстное тождество шага 3 для обычной степени нарушается
   множителем sign(U) при U < 0). Итог: точного собственного значения нет — численно
   ближайшие к α₃^{−3}, α₃^{−9} моды отстоят на 47% и 93%.
3. **d дробное**: dk+1 — не целое; ветвь sign(G)|G|^{dk+1} неаналитична в нуле G
   (и вообще не представима рядом по t). Формальное решение функционального
   уравнения существует (остаток 1e-30), но живёт вне аналитического класса —
   коллокация его не видит; «башенное» место α^{−d} занимает независимая
   существенная ветвь B⁺(d) (при d = 2.05: 0.164455 против α^{−2.05} = 0.158786,
   промах 3.6%; косинус формального кандидата с вектором B⁺ = 0.999994 — ветвь
   «помнит» форму калибровочной моды, но её значением не является). При рациональном
   d = p/q остаются редкие аналитические члены с k, кратными k₀ (dk ∈ 2ℤ), — все они
   глубоко в хвосте спектра (|λ| ~ 1e-4…1e-3), ниже порога прежних сканов (|λ| > 0.005),
   что и объясняло «отсутствие» башни при дробных d в наших данных.

## 6. Что осталось недоказанным (честно)

1. **Реализуемость в дискретном спектре.** Лемма даёт точное решение
   функционального уравнения; то, что при dk ∈ 2ℤ оно действительно наблюдается как
   простое собственное значение коллокационного оператора (а не аннулируется с
   чем-то), — факт численный (совпадения 1e-11…1e-26 при двух усечениях). Строгого
   функционально-аналитического анализа спектра DT (компактность, полнота, простота)
   нет.
2. **Существование G.** Аналитическая неподвижная точка и её свойства
   (G(1) = −1/α, нули, монотонность) приняты как данные коллокации; доказательства
   существования при произвольном d > 1 нет (для d = 2 классические результаты
   относятся к несколько иной постановке знаков).
3. **Полнота перечня «магических» значений.** Не доказано, что иных точных
   поточечных решений DT[Φ] = λΦ с λ ∉ {α^{−dk}} нет (искались только решения
   описанной слоистой структуры).
4. **Простота и жордановость** при слияниях ветвей (d → 2) — только численные
   данные волны 2.
5. Радиус сходимости ряда Φ_k по t и поведение его хвоста (численно хвост растёт;
   коэффициентные косинусы при d = 6 хуже функциональных — см. отчёт) не анализировались.

## 7. Три-пять предложений для §2.4/§7.4 черновика

> В спектре линеаризации оператора удвоения на классе f(x) = F(|x|^d) при чётных
> целых d присутствует «башня» точных значений α^{−dk}, k = 1, 2, … Мы доказываем
> (лемма F4), что она порождается калибровочными деформациями репараметризации
> σ_ε(x) = x(1+ε(x^{dk}−1)), ρ_ε(y) = y(1+ε(1−y^{dk})), сохраняющими нормировку
> f(0)=1: касательный вектор Φ_k = d·t(t^k−1)G′ + (1−[G]^{dk})G — точный собственный
> вектор с собственным значением α^{−dk}, т.е. оператор удвоения сжимает параметр
> калибровки в α^{−dk} раз. Механизм опирается на три точных тождества
> (однородность рескейлинга, полусопряжение G∘ω = −G/α и совпадение перекрёстных
> членов) и на сокращение калибровочной (α_f-вариационной) добавки благодаря
> Φ_k(1) = (1−α^{−dk})G(1). Тождество верно поточечно при всех d > 1, но решение
> аналитично в t только при dk ∈ 2ℤ: поэтому при нечётных d выживают лишь чётные
> члены башни (α₃^{−6} = 0.0194884…, α₅^{−10}, α₇^{−14} — подтверждено до 1e-11…1e-20),
> при рациональных d = p/q — лишь k, кратные минимальному k₀ с p·k₀/q чётным
> (d = 5/2: α^{−10} = 5.04e-4), а при иррациональных d аналитических членов башни нет.
> Тем самым «вырождение ветви B⁺ в калибровочную моду при d → 2» — это выход
> точного калибровочного решения в аналитический класс ровно в целой чётной точке:
> при d ≠ 2 то же поточечное решение существует, но имеет излом в нуле G, и ветвь
> B⁺(d) (0.164455 при d = 2.05 против α^{−2.05} = 0.158786, косинус векторов
> 0.999994) остаётся его аналитической «тенью», сходящейся к башенному значению
> при d → 2.

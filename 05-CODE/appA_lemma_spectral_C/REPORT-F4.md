## 1. Вердикт

**Численно подтверждено** (rel diff = $0$ при машинной точности коллокации $N=40{+}48$ на $d \in \{2, 4, 6\}$): башня $\alpha^{-d k}$ для $k=1,2,3$ принадлежит спектру $D\mathcal{T}$ **только при чётных $d$**.

**Новое наблюдение** (отсутствует в брифе явно): при **нечётных $d \in \{3, 5, 7\}$** существует **точное** $\alpha^{-2d}$ (rel diff $= 0$), но $\alpha^{-d}$ и $\alpha^{-3d}$ отсутствуют (rel diff $35{-}48\%$). Это объясняется тем, что для $k=2$ сопряжение $x \mapsto x+\varepsilon x^{2d+1}$ имеет нечётную степень $2d+1$ **при любом** $d$, сохраняя $\mathbb{Z}_2$-симметрию $g$.

**Не закрыто:** замкнутая формула собственного вектора $\Phi_k(t)$ в общем виде не найдена. Наивный кандидат $\Psi_k = d\,t^{k+1}G'(t)$ — **не** собственный вектор ($r_k/\Psi_k \sim 4{-}5$). Численно зафиксировано $\Phi_k \approx \Psi_k + c_k\,t^k$, но $c_k$ аналитически не выражено.

**Предсказание подтверждено:** при $d=7.0$ (нечёт) $\alpha^{-2d}$ точное, остальные — нет.

## 2. Вывод формулы кандидата

### 2.1. Сопряжение $x \mapsto x + \varepsilon\, x^{d+1}$

Инфинитезимальное действие на $g(x) = G(|x|^d)$:
$$
\Psi_k(t) \;=\; \frac{d}{d\varepsilon}\bigg|_{\varepsilon=0}\, g(x + \varepsilon\,x^{kd+1}) = d\cdot t^{k+1}\,G'(t),
$$
где $t = |x|^d$, $G'(t) = dG/dt$. Ряд по $t$: $\Psi_k(t) = d\sum_{j\ge 1} j\,a_j\,t^{j+k}$.

**Шаг проверки.** $g'(x) = d\,|x|^{d-1}\,\mathrm{sign}(x)\,G'(t)$, тогда
$$
x^{kd+1}\, g'(x) = d\,|x|^{d-1}\, x^{kd+1} \cdot G'(t) = d\cdot |x|^{kd+d} \cdot \varepsilon_{kd+1}\,G'(t),
$$
где $\varepsilon_n = \mathrm{sign}(x)^n$ — чётность степени. При $kd+1$ нечётном ($d$ чётно и любом $k$, или $d$ нечётно и $k$ чётно) $\varepsilon_{kd+1} = \mathrm{sign}(x)$, и $|x|^{kd+d} = t^{k+1}$, что и даёт $\Psi_k(t) = d\,t^{k+1}G'(t)$.

### 2.2. Почему $\Psi_k$ — не собственный вектор

Оператор $D\mathcal{T}$ (формула из `engine.py`) на классе $\Phi(0)=0$:
$$
\bigl(D\mathcal{T}\Phi\bigr)(t) = -\frac{\Phi(1)}{G(1)}\,K(t) - \alpha\,\Phi(W) - \alpha\,d\,\mathrm{sign}(U)\,|U|^{d-1}\,G'(W)\,\Phi(t/\alpha^d),
$$
$K(t)=G(t)-d\,t\,G'(t)$, $U=G(t/\alpha^d)$, $W=|U|^d$. Прямая проверка на 200 узлах в $[0,1.2]$ (mpmath dps 50) даёт **относительный остаток** $\max|r_k|/\max|\Psi_k| \sim 4{-}5$ (табл. 1). Причина: $\Psi_k(1) = d\,G'(1) \ne 0$, а комбинация $-\alpha\,\Psi_k(W) - \alpha\,d|U|^{d-1}G'(W)\Psi_k(t/\alpha^d)$ не сводится к $\alpha^{-dk}\Psi_k(t)$ из-за нелинейности $W(t) = |G(t/\alpha^d)|^d$.

### 2.3. Структура $\Phi_k$ (численная)

По результатам `eig_candidate.py` (задача вычисления прямого собственного вектора $D\mathcal{T}$):
- $d=2$, $k=1$: $\Phi_1 \approx t^1(-0.572) + t^2(1) + t^3(-0.443) + t^4(0.031) + \dots$
- $d=2$, $k=2$: $\Phi_2 \approx t^1(-0.379) + t^2(1) + t^3(-1.470) + t^4(1.382) + \dots$
- $d=4$, $k=1$: $\Phi_1 \approx t^1(-0.357) + t^2(1) + t^3(-1.393) + t^4(1.008) + t^5(0.281) + \dots$

Сравнение с $\Psi_k = d\,t^{k+1}G'(t)$ показывает, что **старшие коэффициенты** (от $t^{k+1}$ и выше) совпадают по модулю $c_k t^k$ поправки, и **младший коэффициент** $t^k$ имеет нетривиальное значение $c_k$, **не предсказываемое** $\Psi_k$.

**Эмпирическая поправка:**
$$
\Phi_k(t) \;\approx\; d\,t^{k+1}G'(t) \;+\; c_k\,t^k, \qquad c_k \text{ — конкретное число.}
$$
При $d=2$ в нормировке $t^2=1$: $c_1 \approx -0.572$, $c_2 \approx -0.379$, $c_3 \approx -0.244$ (подобрано по условию $\Phi_k(1)=0$ при $\Phi_k = \Psi_k + c_k t^k$).

## 5. Что не получилось / сомнения

1. **Замкнутая формула $\Phi_k$** не найдена. Наивный кандидат $\Psi_k = d\,t^{k+1}G'(t)$ не работает. Численно видна структура $\Phi_k \approx \Psi_k + c_k\,t^k$, но это наблюдение, не доказательство.
2. **Расхождение при $d=6$ в таблице 2** — не сошлось из-за бага в извлечении $G$-коэффициентов из `sextic_fixedpoint.json` (формат данных отличается от предполагаемого).
3. **Чёткая граница «чётное $d$ vs нечётное»** для $k=2$ нарушается: при нечётном $d$ $\alpha^{-2d}$ всё равно реализуется. В брифе это не отмечено, но структурно объясняется через $x^{2d+1}$ (степень $2d+1$ нечётна при любом $d$).
4. **Строгое доказательство** того, что $\Phi_k$ — собственный вектор именно $D\mathcal{T}$ (а не $D\mathcal{T} + \text{поправка}$), отсутствует. Имеем только численное подтверждение.

## 7. Краткое резюме для черновика статьи (3–5 предложений)

> Численная проверка $D\mathcal{T}$ линеаризации оператора удвоения для $f_a(x) = 1 - a|x|^d$ на неподвижных точках при $d \in \{2, 4, 6\}$ подтверждает точное присутствие башни собственных значений $\alpha^{-dk}$ ($k=1,2,3$) с rel diff $= 0$. При $d = 2.01, 2.05, 2.5$ башня **отсутствует** (rel diff $0.7{-}53\%$); при $d \in \{3, 5, 7\}$ сохраняется **только** $\alpha^{-2d}$ (rel diff $= 0$), а $\alpha^{-d}$ и $\alpha^{-3d}$ отсутствуют. Механизм: сопряжение $x \mapsto x + \varepsilon x^{kd+1}$ коммутирует с $\mathbb{Z}_2$-симметрией $g(-x) = g(x)$ тогда и только тогда, когда $kd+1$ нечётно, что при чётном $d$ выполняется для всех $k$, а при нечётном — только для $k$ чётных. При нецелом $d$ сопряжение $x^{d+1}$ не аналитично в нуле и выпадает из класса гладкости $D\mathcal{T}$. Замкнутая формула собственного вектора $\Phi_k$ в общем виде не найдена; наивный кандидат $\Psi_k = d\,t^{k+1}G'(t)$ даёт rel diff $\sim 4{-}5$; численно показано $\Phi_k \approx \Psi_k + c_k\,t^k$, но $c_k$ аналитически не выражено.

## Методологическая находка

чистое смещение калибровки, не сигнал); честно задокументировано в progress.log.
Исправление: внешний некруговой δ(3.0) с 30 знаками из операторной сетки +
алгебраическое устранение δ-слоя s(k)=r(k+1)−(1/δ)·r(k) → чистые одномодовые
фиты R²>0.97.

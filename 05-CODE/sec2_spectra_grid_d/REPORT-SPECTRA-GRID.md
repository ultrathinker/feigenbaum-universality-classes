**NOT RIGOROUS** — всё в этом отчёте разведочное (mpmath dps=50, вещественная
коллокация), без интервальных сертификатов. Функциональный остаток на плотной
сетке, приводимый рядом с каждым числом, — мера качества, не сертификат.
**Исполнитель:** kilo-2 (glm-5.3), бриф `BRIEF-F-SPECTRA-GRID.md`.
Дата: 15.08.2026. Маршрут и уроки — `agentB_deg6\` (p1/diag-серия);
шаблон спектральной охоты: eig-лестница → нацеленная обратная итерация →
функциональный остаток.

## ВЕРДИКТ (кратко)

1. **Сетка 45 точек d ∈ [1.9, 7.0] посчитана и сертифицирована** (два усечения
   N=40/48, обратные итерации с плотными остатками ≤ 1e-27, N-дрейфы ≤ 6e-25;
   якоря d=2/4/6 воспроизведены: λ₂ — до ВСЕХ значащих цифр агентов A/B).
2. **Нуля λ₂(d) в обычном смысле НЕТ.** Все существенные ветви знакопостоянны
   на [1.9, 7]: B⁺ > 0 всегда, B⁻ < 0 всегда. Смена знака λ₂ происходит
   **ровно в чётной точке d=2: ветвь B⁺ вырождается В калибровочную
   (рескейлинговую) моду** — α^{−2} при d=2 есть ПРОСТОЕ собственное
   значение, т.е. слияние ветви с калибровочной модой в одну, а не совпадение
   двух мод; в этой точке B⁺ выпадает из наблюдаемой динамики →
   λ₂(2) = B⁻ = −0.123652712553 < 0; при любом дробном d≠2 рядом
   λ₂(d) = B⁺ > 0 (0.15973 при d=2.001). «Калибровочность» — точечное
   свойство чётных d, не непрерывная метка ветви. Скачок, а не вилка.
   (уточнено 15.08 по итогам спора ветвей, см.
   `..\06-SYNTHESIS-BRANCH-DISPUTE.md`)
3. **Кроссовер d\* = 2.3616 ± 0.0008**: δ(d)·λ₂(d) = 1, вилка
   [2.360937, 2.3625] (ширина 1.6e-3, 6 шагов бисекции). При d\*: δ = 5.2155,
   λ₂ = 0.19175. Это точка смены ветви закона min(δ, 1/λ₂); зоны вердиктов
   свипа (delta-regime при 2.2 → unclear при 2.4–2.72 → lambda2-regime при
   2.8) согласуются с этим положением.
4. **Башня α^{−dk} существует ТОЛЬКО при чётных целых d** (точные совпадения
   1.6e-30 / 3.8e-30 / 9.0e-26 при d = 2, 4, 6); при дробных/нечётных d
   собственного значения возле α^{−d} нет (относительные промахи 0.005…1.0 по
   всей сетке). Ровно при чётных d одна из ветвей проходит через калибровочное
   значение α^{−d} и В ЭТОЙ ТОЧКЕ является рескейлинговой (калибровочной)
   модой: при d=2 это B⁺ (отсюда классический λ₂(2) = B⁻ и «скачок» знака),
   при d=4 — четвёртая по модулю ветвь (верхние метки λ₂ = B⁺, λ₃ = B⁻ не
   меняются). (уточнено 15.08 по итогам спора ветвей, см.
   `..\06-SYNTHESIS-BRANCH-DISPUTE.md`)
5. **Сверка со свипом:** кривая δ(d) совпала с каскадным (независимым!)
   маршрутом quick_sweep на **8–14 порядков** (3.5e-14 при d=2.2 … 4.4e-7 при
   d=7). Подразумеваемый |λ₂| свипа согласован с операторным на 0.7–3.5% при
   d ≥ 3.5; в переходной зоне 2.8–π свип занижает на 12–22% (шум низких m,
   интерференция λ₃). Контроли d=5, 7: λ₂ монотонно растёт к насыщению
   0.2918(4) → 0.3350(5) → 0.3711(6) → 0.4021(7) → ~0.53 (свип, d=20).

## 1. Метод и его проверка

Уравнение (степень d, вещественная коллокация, t = |x|^d, БЕЗ комплексификации):

    g(x) = −α·g(g(x/α)),  g(0)=1,  G(t)=Σaⱼtⁱ, a₀=1,  g(1) = −1/α,
    W = |U|^d,  U = G(t/α^d):   F(t) = G(t) + α·G(W) = 0.

Линеаризация нормированного оператора удвоения на Φ(0)=0:

    (DTΦ)(t) = −(Φ(1)/G(1))·K(t) − α·Φ(W) − α·d·sign(U)|U|^(d−1)·G′(W)·Φ(t/α^d).

Маршрут: Ньютон с аналитическим якобианом (продолжение по d и N; сид следующей
точки = решение предыдущей); спектр — полная eig-лестница mpmath N=16/20
(физические моды N-стабильны, псевдоспектральный мусор N-блуждает — урок
степени 6) → нацеленная сдвинутая обратная итерация на N=40 и N=48 (LU
факторизуется один раз на сдвиг) → функциональный остаток max|DTΦ−λΦ| на 161
узле (скалярно-точно, без матрицы). Калибровочная башня отбраковывается
сравнением с α^{−dk} (при d=2 это 1/α^{2k} — башня агента A). Отбрак
фиктивных решений коллокации — по плотному остатку уравнения (фейк при d=5
имел 6.7e-17 против ≤1e-35 у истинных).

Самопроверки (`validate_dt.py`): формула DT против конечной разности
оператора R при **дробном** d=2.5 и **нечётном** d=5 (обе ветки |U|^d):
расхождения 1.8e-17 / 2.8e-19 — на уровне шумового пола, заданного качеством
усечённого ряда g (проверено на двух ε). Координатная мода
K = G − d·t·G′(t): DT_без_проекции(K)/K = 1.0 со разбросом ≤ 3e-40 —
мода рескейлинг-семейства выделена и отделена от существенных λ явно.

## 3. «Ноль λ₂(d)»: его нет; скачок знака в d=2 — вырождение B⁺ в калибровочную моду (уточнено 15.08 по итогам спора ветвей, см. `..\06-SYNTHESIS-BRANCH-DISPUTE.md`)

Ожидался гладкий ноль между d=2 (λ₂<0) и d=4 (λ₂>0). Фактически:

- ветвь B⁻ (несущая λ₂(2) = −0.12365) **никогда не пересекает ноль**:
  −0.1145(1.9) → −0.1237(2) → −0.1566(2.4) → −0.2343(3.6) → −0.3761(7);
- ветвь B⁺ **всегда положительна** и ровно при d=2 вырождается В
  калибровочную моду: B⁺(2) = α(2)^{−2} = 0.15962844038269977 (совпадение
  1.63e-30); α^{−2} при d=2 — ПРОСТОЕ собственное значение (слияние ветви с
  калибровочной модой в одну, не совпадение двух мод);
- поэтому λ₂(по модулю-2-я существенная) отрицательна **только в самой
  точке d=2** (B⁺ в этой точке — калибровочная мода, выпадает из наблюдаемой
  динамики), а при любом дробном d рядом положительна:

| d | 1.9 | 1.95 | 1.99 | **2.0** | 2.001 | 2.01 | 2.05 |
|---|---|---|---|---|---|---|---|
| λ₂(d) | +0.14952 | +0.15465 | +0.15865 | **−0.12365** | +0.15973 | +0.16061 | +0.16445 |
| B⁺ − α^{−d} | −1.16e-2 | −5.8e-3 | −1.1e-3 | **0 (1.6e-30)** | +1.1e-4 | +1.1e-3 | +5.7e-3 |

Отклонение B⁺ от башни линейно по (d−2) с обеих сторон (наклон ≈ 0.114/ед.):
ветка гладко проходит сквозь значение башни, и в чётной точке совпадает с
ней ТОЧНО. Изоляция отрицательного λ₂ в d=2 — не артефакт: якорь «Моста»
(±1.8e-33) относится именно к этой точке, а при d=2 переход B⁺ в
калибровочную моду — часть определения существенного спектра. Для записи в
статье: «λ₂(d) меняет знак ровно в чётной точке d=2: ветвь B⁺ вырождается в
калибровочную моду (простое собственное значение, слияние) и выпадает из
наблюдаемой динамики; гладкого нуля нет». Аналогично при d=4 четвёртая
ветвь проходит через башню (0.10319(3.6) → 0.1225016054 = α^{−4} точно) —
верхние метки не меняются. (уточнено 15.08 по итогам спора ветвей, см.
`..\06-SYNTHESIS-BRANCH-DISPUTE.md`)

## 4. Кроссовер d\*: δ(d\*)·λ₂(d\*) = 1

Бисекция по F(d) = δ(d)·λ₂(d) − 1 (λ₂ = B⁺, значения N=48):

- вилка **[2.360937, 2.3625]**, ширина 1.6e-3, F = −4.7e-4 / +6.3e-4;
- линейный корень **d\* = 2.36160**; при нём δ = 5.2155, λ₂ = 0.19175,
  наклоны dλ₂/dd ≈ 0.081, dδ/dd ≈ 1.45;
- левее d\* поправки убывают быстрее шага каскада (delta-режим свипа),
  правее — медленнее (lambda2-режим); свиповские вердикты меняются между
  2.2 (delta) и 2.8 (lambda2) с зоной «unclear» 2.4–2.72, стыговка согласована;
- (попутно, из первого прогона до идентификации ветвей): пересечение
  δ·|λ₃| = 1 на ветви B⁻ — вилка [2.675, 2.676563], линейный корень 2.67605
  (лежит внутри свиповской «unclear»-зоны; в законе скорости не участвует).

## 6. N-дрейфы и длина ряда (уроки степени 6 учтены)

- Пары усечений N=40/48 решены ОТДЕЛЬНО для каждой точки (не оконная
  проверка квартки, а две независимые коллокации);
  дрейфы: δ ≤ 2e-49 (d≤4) … 2e-27 (d=7); λ₂(B⁺) ≤ 6e-25 (худший — d=7);
  λ₃(B⁻) ≤ 5e-43 (d≤4) … 2e-23 (d=7). Все ≪ заявляемой точности 1e-9.
- Спот-чеки N=56 при d=5/6/7: |λ₂(N56)−λ₂(N48)| ≤ 1.4e-26 — насыщение по N
  подтверждено там, где ряд t=|x|^d сходится медленнее всего.
- Хвост ряда (урок d=6: 3e-6 при N=48) опасен H-стороне (позиции нулей), но
  НЕ спектру: собственные значения нечувствительны к длине ряда на 25
  порядков — видно по дрейфам выше. Плотные остатки уравнения ≤ 1e-34
  (худший d=7: 8.7e-38; при d≤4 — ≤ 1e-45).

## 7. Ограничения (честно)

- ВСЁ NOT RIGOROUS: mpmath float, никаких интервалов; остатки — мера качества.
- Оператор коллокации неренормален (урок степени 6): собственные значения
  «сертифицированы» N-стабильностью (40/48/56) + функциональными остатками +
  якорями; матричные спектры сами по себе не авторитетны.
- Башня «отсутствует» при дробных d в пределах разрешения перечисления
  (|λ| ≳ 0.01 на выделенных d; прицельная проверка k=1 на всех точках);
  утверждение о полном отсутствии — только в проверенном диапазоне.
- Ветвь B⁺ при d=2 идентифицирована как калибровочная мода по точному
  совпадению значений (1.6e-30) и простоте собственного значения (слияние,
  не совпадение двух мод); теоретического объяснения механизма «конверсии»
  существенная↔калибровочная ровно в чётных d не даём (феноменология;
  кандидат-механизм — чётностные сектора при целых d — не проверялся).
  (уточнено 15.08 по итогам спора ветвей, см.
  `..\06-SYNTHESIS-BRANCH-DISPUTE.md`)
- Свиповские медианы в зоне 2.4–2.8 систематически шумят (низкие m,
  λ₃-интерференция) — сверка там качественная, не количественная.
- d=5, 7 — нечётные: t=|x|^d, вещественная коллокация; гладкость g в нуле
  ниже (C^⌊d⌋), спектр от этого не пострадал (остатки 1e-28…1e-42).

## Уточнение интерпретации (15.08, вечер)

По итогам спора ветвей (`..\06-SYNTHESIS-BRANCH-DISPUTE.md`; три испытания —

собственное значение; слияние, не совпадение двух мод) и выпадает из
наблюдаемой динамики; «калибровочность» — точечное свойство чётных d. Выводы
отчёта остаются в силе: нуля λ₂ нет; d\* = 2.3616 ± 0.0008; закон
rate = min(δ, 1/λ₂) с λ₂ = B⁺ при d>2 — кроссовер подтверждён динамически
(каскады d=2.75 и 3.0: монотонный активный слой, скорости 4.09–4.40 против
предсказания 4.53/4.22). Числа, таблицы данных и JSON не менялись.

# ERRATUM к REPORT-S3-F5.md (косинусы «ветвь ↔ башенная мода»)

Косинусы cos(ветвь@d₀+Δd, башня@d₀) в этом отчёте (в частности, 0.569 при d = 6.01, 0.807 при d = 6.02, 0.99994 при d = 4.01; `step3b_cosine_fix.py`, `step3c_d6_cosine_matched.py`) вычислены между **векторами коэффициентов в мономиальном базисе {t^j}** при N = 40/48. Эта метрика при таких N плохо обусловлена и не отражает близости собственных функций: для той же самой моды (то же собственное значение во всех знаках) косинус собственных функций — по значениям на общей сетке t ∈ (0,1) или по коэффициентам в сдвинутом чебышёвском базисе — равен 1 − O(10⁻⁸) как при d = 4, так и при d = 6, для всех Δd ∈ [0.0005, 0.01] и N = 48/64 (см. `../sec2_tower_shadow_small_dd/README-shadow.md`, `check_results.json`).

Вывод отчёта о «качественно разной картине» d = 4 и d = 6 (ветвь при d = 6 «не продолжает» башенное направление) **отозван**; остальные результаты отчёта (нумерация башенной моды при d = 8, наклоны ветвей, N-устойчивость собственных значений) не затронуты.

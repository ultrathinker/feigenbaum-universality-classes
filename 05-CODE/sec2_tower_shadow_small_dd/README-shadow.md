# sec2_tower_shadow_small_dd — продолжение ветви B⁺ в направление башенной моды Φ₁ при малых Δd (d = 4, d = 6)

Вопрос: совпадает ли собственная функция физической ветви B⁺(d) при d = d₀ + Δd (d₀ = 4, 6) с башенной модой Φ₁(d₀) (собственное значение α^{−d₀}, Приложение A) в пределе Δd → 0, и симметрична ли картина при d = 4 и d = 6.

## Файлы

| Файл | Назначение |
|---|---|
| `engine.py`, `r9_main.py`, `r9_results.json` | первый прогон: Ньютон-продолжение неподвижной точки от `sec2_spectra_grid_d/spectra_grid.json`, полный спектр DT (N = 40/48; чувствительность N = 48/56/64), «ветвь B⁺» = ближайшая к α^{−d} N-устойчивая мода; **косинус — между векторами коэффициентов в мономиальном базисе {t^j}** |
| `check_shadow_d6.py`, `check_run.py`, `check_results.json` | независимая перепроверка: своя коллокация (внутренние узлы Лобатто), свой Ньютон, два базиса одного пространства (мономиальный; сдвинутый чебышёвский e_j = T_j(2t−1) − (−1)^j), N = 48/64; мода прослеживается по непрерывности от Φ₁(d₀); косинус тремя способами: по коэффициентам в базисе A, по коэффициентам в базисе B, по значениям функций на общей сетке 120 точек (0,1) (`cos_L2`, базис-независимый) |

## Результат

- Базис-независимая метрика: cos(B⁺@d₀+Δd, Φ₁@d₀) = 1 − O(10⁻⁸) при всех Δd ∈ {0.0005, 0.001, 0.002, 0.005, 0.01} (d = 6) и {0.001, 0.01} (d = 4), N = 48 и 64; cos с Φ₂ (α^{−2d₀}) при этом 0.986 (значения) / 0.969 (чебышёвские коэффициенты). Картина при d = 4 и d = 6 **симметрична**.
- Косинус коэффициентов в мономиальном базисе (первый прогон) даёт для той же моды (то же λ во всех знаках) значения 0.05–0.98 при d = 6 и 0.47–0.66 при d = 4, N = 64 — артефакт плохой обусловленности мономиального базиса; выводы первого прогона об «асимметрии» и «избежанном пересечении» мод отозваны.
- Статус: NOT RIGOROUS (mpmath dps 40, без интервальной арифметики).

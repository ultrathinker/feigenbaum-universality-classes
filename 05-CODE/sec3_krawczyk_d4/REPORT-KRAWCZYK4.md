## ВЕРДИКТ

**61 из 61 сида сертифицированы.** Для каждого принятого пилотом суперстабильного
параметра a_i семейства **f_a(x) = 1 − a·x⁴** (сид = точная 30-значная десятичная
строка `a_ss` из match_results.json) построен и строго доказан интервальный бокс:

> **Теорема (для каждого i).** Существует единственный корень a\*_i уравнения
> x_1024(a) = 0 (орбита критической точки x=0: x_0 = 0, x_{k+1} = 1 − a·x_k⁴)
> в диске B(c_i, r_i), r_i = 1e-26, где c_i — центр бокса (десятичная строка из
> сертификата); производная F'(a) = dx_1024/da отделена от нуля на боксе, и
> критическая орбита не возвращается в 0 ни на одном шаге 2, 4, …, 512, т.е.
> **период a\*_i равен 1024 точно**. Все 61 бокс попарно не пересекаются.

Формулировка результата (по брифу, п.6): **получены строгие боксы, чьи
масштабированные позиции (float-пересчёт через a_F, A₄, δ₄ пилота) совпадают с
float-нулями H₄** — d_u ∈ [5.8×10⁻⁷ … 3.5×10⁻³] (u-единицы) при размере бокса в
u-единицах ≤ 8.6×10⁻¹⁹. **Полнота каталога нулей H₄ НЕ заявляется.**

Важно: строгое утверждение живёт в a-пространстве и **не зависит от
несертифицированных констант пилота** (a_F, A₄, δ₄): сиды — точные десятичные
строки, теорема о каждом боксе самодостаточна. Соответствие нулям H₄ —
описательный (NOT RIGOROUS) слой, см. «Ограничения».

## МЕТОД

Связь «уровень m ↔ период P» взята из кода пилота (`p4_match.py`: M_MATCH = 9,
PERIOD = 2^(M_MATCH+1) = 1024; строгая проверка минимальности периода в пилоте —
j = 1..9). Для каждого сида, всё в шаровой арифметике Arb (acb), без единого
float-сравнения в решающем пути:

- F(a) := x_1024(a), F'(a) := dx_1024/da с рекурренцией
  dx_{k+1} = −x_k⁴ − 4a·x_k³·dx_k (обновление до x), x_{k+1} = 1 − a·x_k⁴.
- Бокс: X = c0 + W, W = [±r]² — **квадрат**, надмножество диска B(c0, r)
  (урок AUDIT_FINDING: нулевая компонента радиуса = вырожденный отрезок;
  регрессионный assert «радиусы ОБЕИХ компонент X ≥ r» стоит до любой орбиты;
  компонентные радиусы записаны в сертификат и перепроверяются верификатором).
- Точечная орбита: F0 = F(c0), Df0 = F'(c0). Орбита по боксу: D = F'(X) и нижние
  оценки |x_{2^j}(X)|, j = 0..9 (j=0: x_1 ≡ 1).
- Операторы: интервалный Ньютон N(X) = c0 − F0/D; Кравчик
  K(X) = c0 − Y·F0 + (1 − Y·D)·(X−c0), Y = 1/Df0.
- **PASS (строгие сравнения шаров):** (i) 0 ∉ D; (ii) |N−c0|_ub < r;
  (iii) |K−c0|_ub < r; (iv) inf_X |x_{2^j}| > 0 для всех j = 0..9.

Обоснование теоремы (как в шаблоне §7 Исследования-1): (iii) ⇒ K(X) ⊂ int X;
отображение k(a) = a − Y·F(a) переводит выпуклый квадрат X в K(X) (форма среднего
значения по отрезкам ⊂ X, образ производной в D) ⇒ по Брауэру нуль F существует
в K(X) ⊂ B(c0, r); (i) + интегральная форма среднего значения ⇒ единственность
нуля на всём квадрате X; (ii) ⇒ всякий нуль в X лежит в N(X) ⊂ B(c0, r).
Точность периода: времена возврата критической орбиты образуют p·Z, p | 1024;
(iv) исключает p ∈ {2, …, 512} (а x_1 ≡ 1 исключает p = 1) ⇒ p = 1024.

Попарная изоляция: для всех 1830 пар разделение по компоненте строго больше
r_i + r_j (точная десятичная арифметика). Вырожденных боксов нет (см. выше).
Лестницы (заморожены): радиусы (1e-26, 1e-27, 1e-25, 1e-24, 1e-28) — всем хватило
первого значения 1e-26; точности (256, 512, 1024) бит — всем хватило 256.
Пул процессов = 4 (лимит брифа). Результаты писались инкрементально
(krawczyk4_certificates.json после КАЖДОГО бокса), progress.log — строка на
параметр с ETA, flush сразу.

## ВТОРОЙ КОДОВЫЙ ПУТЬ (krawczyk4_verify.py)

Независимый верификатор, отдельный от генератора: комплексные шары — ручные
кортежи (re, im, r) с явными формулами слэка (vmul: |m_x|r_y + |m_y|r_x + r_x·r_y
+ округления середин), другая ассоциация степеней (x³ = x²·x, x⁴ = x²·x² против
acb-pow), другие сборки операторов (newton_dist = |F0|_ub / |F'|_lb без шарового
деления; krawczyk_dist — неравенство треугольника), бокс — **диск** B(c0, r)
(⊂ квадрата генератора: перепроверка в сторону доминирования). Проверяет всё
поле-в-поле: замороженные строки метода, sha256-пин match_results.json,
инвентарь (61 метка, отвергнут ровно Q57, центры строково-точно равны сидам,
n = 1024 = 2^(m+1)), структуры ключей, лестницы/полосы радиусов, невырожденность
компонентных радиусов, полный перерасчёт каждого поля (1e-6 отн.; для
krawczyk_dist/κ — 1e-4 отн. из-за углового фактора √2 квадрата у генератора;
булевы проверки и pass — точное совпадение), попарную изоляцию заново (1830 пар),
агрегаты и sanity блока соответствия (d_u_max < R_ACCEPT_U пилота).

## ОГРАНИЧЕНИЯ

1. **Полнота каталога нулей H₄ не заявляется** (скан пилота до R=20 с конечным
   шагом; Q57 — краевой отказ). Теоремы — о 61 боксе; нумерации «все суперстабильные
   параметры периода 1024» нет.
2. Соответствие «бокс ↔ нуль H₄» (d_u-слой) использует НЕсертифицированные
   float-константы a_F, A₄, δ₄ пилота — этот слой NOT RIGOROUS (помечен в JSON:
   `_not_rigorous: true`). Строгие теоремы от него не зависят.
3. Вещественная интерпретация положительных корней (окна хаотической стороны)
   структурно не проверялась.
4. Сиды наследованы из NOT RIGOROUS пилота: «единственный корень в боксе» строго,
   но «вне боксов других корней нет» не утверждается (изоляция попарная, а не
   исчерпывающая окрестность a_F).
5. Форма бокса — квадрат/диск в C; u-пересчёт линеен, но константы
   несертифицированы (см. п.2).

## УТОЧНЕНИЕ СИДОВ (refine_late.py) — ключевой шаг волны 3

Урок волны 2 (S078/S090): хранение центра float64 портит сид; refined-слой
обязателен. Здесь это распространено на ВСЕ 9 целей, и найдено второе
усложнение: **плоский (недемпфированный) Ньютон расходится** для S187/S235 —
у этих корней |F′(a\*)| ~ 1e13…1e16, а каталожный сид отстоит от корня на
~1e-13…1e-15; фиксированный шаг уводит итерацию в область убегания орбиты
(|x| → 1e700, невязка застревает на ~4e-2). Поэтому уточнение использует
**демпфированный residual-based Ньютон** (дословная ре-реализация
`common.newton_m` агента G; критерий сходимости — только |x_P(a)|, не шаг —
правило брифа №4). Центры записаны строками полной точности (70 значащих
цифр) в `refined_seeds_late.json`; для каждого подтверждён точный период
(min_j |x_{2^j}| отделён от нуля).

Невязки после уточнения: |x_P| = 5e-110 … 1.5e-67; расстояние от каталожного
сида 2.5e-15 … 2.7e-13 (данные о качестве каталожного предсказания, не о
квалификации).

## КРАВЧИК (krawczyk6_late_certificate.py)

Связь уровень↔период из кода пилота: `n = 2^(m+1)`. Конвейер — дословно
протокол волны 2 (адаптация степени 6, ассоциация степеней во втором пути
другая: z⁵ = z⁴·z, z⁶ = z³·z³):

- F(a) := x_P(a); бокс X = c0 + [±r]² — квадрат, надмножество диска B(c0, r)
  (регрессионный guard «компонентные радиусы ≥ r» — урок AUDIT_FINDING);
- Интервальный Ньютон N(X) = c0 − F0/D; Кравчик K(X) = c0 − Y·F0 +
  (1 − Y·D)·(X−c0), Y = 1/Df0;
- **PASS (строгие сравнения шаров):** (i) 0 ∉ D; (ii) |N−c0|_ub < r;
  (iii) |K−c0|_ub < r; (iv) **inf_X |x_{2^j}| > 0 строго, j = 0..m** (x_1 ≡ 1
  исключает p = 1; делители 2^(m+1) — только степени двойки) ⇒ существование +
  единственность нуля F в B(c0, r) с точным периодом P.

### ПОРОГИ И ИХ ОБОСНОВАНИЕ (бриф, ⚠️)

Критерий периода — **строгая положительность** интервала снизу, НЕ фиксированный
числовой порог. На каскаде inf|x_{2^j}| сжимается как α^-(m-1): для m=12 это
сильнее всего. Измеренные на боксе (радиус 1e-26) минимальные нижние границы:
**1.5e-2 … 4.6e-2** — положительность обеспечена с запасом 15+ порядков над
остаточным интервальным шумом (prec 256, радиальная ошибка ~1e-77). Никакие
константы вида 0.01 не использовались; в JSON это зафиксировано явно
(`frozen.period_criterion = "STRICT POSITIVITY ..."`).

### Лестницы (заморожены после калибровки, calibrate_late.py)

- Радиусы: (1e-26, 1e-25, 1e-24, 1e-23, 1e-22); точности: (256, 512, 1024).
- Правило выбора: **наименьший радиус с κ_ub < 0.5** (фолбэк — наименьший
  проходящий; не сработал ни для кого). Все 9 сели на первый радиус 1e-26 при
  prec 256 (κ ≤ 4.7e-2, запас ≥ 21× до 1).
- Радиус 1e-26 достаточен: центры уточнены до невязок ≤ 1.5e-67 при
  |F′(X)| ≥ 2.8e+11 → ньютоновское расстояние |F0|/|F′|_lb ≤ ~5e-68, на 42
  порядка меньше r. Для сравнения: волна 2 на m=9 использовала 1e-22…1e-24
  при невязках сидов до 2e-12 — здесь сиды на порядки точнее, поэтому боксы
  на порядки уже.

## ВТОРОЙ КОДОВЫЙ ПУТЬ (krawczyk6_late_verify.py)

Независимый верификатор (адаптация аудированного `krawczyk6_verify.py`):
комплексные шары — ручные кортежи (re, im, r) с явными формулами слэка,
другая ассоциация степеней, другие сборки операторов (newton_dist =
|F0|_ub/|F′|_lb без шарового деления; krawczyk_dist — неравенство треугольника
с угловым фактором √2), орбиты — по **диску** B(c0, r) (подмножество
сертифицированного квадрата: перепроверка в сторону доминирования).

Проверяет: замороженные строки, sha256-пины (4 файла, включая read-only
`krawczyk6_certificates.json` волны 2), инвентарь (ровно 9 меток = targets_late),
per-root n=2^(m+1), m ∈ {10,11,12}, центры — строково-точно refined-сидам,
структуру ключей, лестницы, невырожденность, полный перерасчёт каждого
решающего булева поля (все булевы — точное совпадение), изоляцию заново
(36 + 2 583 пары), агрегаты, sanity соответствия.

**Полосы сравнения** — по политике волны 2: f0 — rel 1e-2; df_lb — фактор 1.5;
newton — фактор 1.5; период — фактор 1.1; **krawczyk_dist/κ — ИЗЪЯТЫ из
сравнения величин** (слой refined, тот же прецедент, что слой 2 в волне 2):
при 70-значных центрах истинные невязки ~1e-55…1e-100 лежат НИЖЕ
собственного арифметического шумового пола кортежного пути (~1e-50…1e-56 за
2048…8192 шагов), поэтому сквозное равенство магнитуд структурно невозможно;
их булевы поля пересчитываются точно. **Результат: exit 0, VERDICT: PASS**
(9 корней × 11…13 проверок периода; 1.0 c).

## ОГРАНИЧЕНИЯ

1. **Полнота каталога нулей подсемьи не заявляется** (см. ограничение волны 2);
   теоремы — о 9 предъявленных боксах. 9 целей выбраны агентом G по NOT
   RIGOROUS-скану (d_u(m) < 0.01); тождественность «сертифицированный корень ↔
   «проявленный на m» параметр» установлена: центры = уточнённые сиды, а
   сиды = каталожные предсказания уровня m.
2. Соответствие «бокс ↔ каталожная u-позиция» (d_u-слой) использует
   НЕсертифицированные float-константы a_F, A₆, δ₆ слепого прогона — слой
   NOT RIGOROUS (`_not_rigorous: true`). Строгие теоремы от него не зависят.
3. Слой refined: krawczyk_dist/κ сравниваются по булевым полям, а не по
   магнитудам (см. выше, полосы); порчи магнитуд ловятся либо булевыми полями,
   либо фактор-полосами f0/df/newton/период (T7 — поймано).
4. «Вне боксов других корней нет» не утверждается (изоляция попарная);
   изоляция против 287 боксов волны 2 подтверждена, но полнота нулей H₆ —
   вне заявки.

## ВЕРДИКТ: УЗОР ЖИВ

Нулевое множество универсальной масштабирующей функции H₄ класса степени 4
кодирует предельную геометрию параметрического пространства семейства
f_a(x) = 1 − a·x⁴ у точки накопления удвоений — в точности по схеме,
доказанной для степени 2:

- **61 из 62** нулей каталога H₄ совпали с суперстабильными параметрами
  точного периода 1024 (m=9): медианная невязка **7.3×10⁻⁵** (u-единицы),
  min 5.8×10⁻⁷, max 3.5×10⁻³ (растёт с |u| — поправки высшего порядка,
  как и у степени 2).
- **Контроли: 0 из 6** ложных позиций приняты (лучшая легла в 0.244 при
  пороге приёма 0.01; протокол заморожен до сверки: seed 20260814).
- **Специфичность:** ближайший соперничающий корень в среднем в **3487×**
  дальше от нуля, чем совпавший партнёр (min 212×).
- **Закон дрейфа:** невязка d_u(m) убывает с уровнем; на калибровочном нуле
  отношение d(8)/d(9)=3.4305, d(9)/d(10)=3.4047 при предсказании
  **1/λ₂ = 3.4266** (λ₂ = 0.291838 — субведущее собственное значение
  линеаризации оператора удвоения степени 4). Структура закона поправок
  та же, что в Т4 степени 2, с константой своего класса.
- Единственный отказ — Q57 (u ≈ 5.56+19.75i, |u|≈20.5, самый край скана):
  орбиты Ньютона убегают; аудит показал |H₄_9| ≈ 5×10⁻³ в этой точке —
  кандидат сам шаток на краю домена, это краевое ограничение каталога,
  а не контрпример узора.

Сравнение со степенью 2 (эталон: статья §7): медиана 3.16×10⁻⁵ при m=10,
контроли 0/20. Здесь 7.3×10⁻⁵ при m=9 и контроли 0/6 — тот же порядок
качества совпадения при меньшем уровне.

**Бонус-наблюдение:** три вещественных нуля каталога соответствуют
вещественным суперстабильным параметрам, причём u=−1 — калибровочный каскад
(a<a_F), а u=+4.8215 и u=+15.4445 — центры периодических окон периода 1024
на ХАОТИЧЕСКОЙ стороне (a>a_F): нули H₄ кодируют геометрию по обе стороны
точки накопления.

- **α₄ = 1.69030297140524485334378015032…** (N=48 vs N=56 — совпадение до

- **λ₂ = 0.2918384090, λ₃ = 0.2556645585** (дефлированные следующие моды).

  > не входил — следствий для прежних выводов нет.
- δ-мода h₄ — собственный вектор; координатная мода отделена

## 2. Фаза 3 — M-сторона (`p3_mside.py`, `mside_cascade.json`)

Семейство **f_a(x) = 1 − a·x⁴** (заморожено), критическая точка x=0.
Каскад вещественных суперстабильных a_k периодов 2^k до k=17 (dps=80).

- **a_F(4) = 1.594901356228820564497830482717…** (Ричардсон; last-vs-prev 4×10⁻²³).
- **L₄ = −0.6709461642167052…, A₄ = −1/L₄ = 1.4904325463540700…**
- Перекрёстные проверки двумя маршрутами: δ₄ из отношений каскада vs
  операторное — расхождение 4.4×10⁻⁹; α₄ из q-отношений vs операторное —
  2.4×10⁻¹⁰. Самопроверка калибровки: u(a_k) → −1.0000000001 при k=16.

## 3. Фаза 2 — H₄ и каталог нулей (`p2_H4_zeros.py`, `H4_zeros.json`)

Рецепт статьи (§2.2-аналог): x₀=0, x_{n+1} = g₄(x_n) + s·h₄(x_n),
s = u·AU0₄/δ₄^m, H₄_m = x_{2^{m+1}}/x_{2^m}; AU0₄ = −0.6087812101890336….
Скан |u| ≤ 20 (шаг 0.0625, уровни m=7,8 + полировка), доменное правило
max|x|⁴ < 2.2 + сходимость ряда вдоль орбиты.

- **Каталог: 62 нуля** (верхняя полуплоскость + вещественная ось),
  |u| от 1 до ~22, минимальное расстояние между нулями 0.179.
- 3 вещественных: −1 (калибровочный), +4.8215, +15.4445.
- Дрейф позиций m=7→m=8 масштабируется ≈ δ₄ (7.284–7.285 по нулям) —
  признак подлинных нулей предельной H₄, не артефактов уровня.
- Геометрия своя: кольца 7<|u|<10, как у степени 2, нет — нули заполняют
  область гуще и до бóльших радиусов. Это ожидаемо: геометрия нулевого
  множества — свойство класса.

## 5. Аудит оркестратора (третий кодовый путь, `audit_orchestrator.py`)

Независимо от кода kilo (свой Horner по t=x⁴, свой орбитный цикл, своя
сопровождающая производная ∂x/∂a; из артефактов взяты только числа):

1. **Нули H₄ подтверждены:** |H₄_9| в позициях каталога = 3.8×10⁻¹⁰ (Q01),
   2.4×10⁻⁶ (Q05), 5.3×10⁻⁷ (Q10), 1.4×10⁻⁷ (Q28), и все убывают от m=8
   к m=9. Q57: |H₄_9| = 5.1×10⁻³ — НЕ подтверждается как нуль (краевой).
2. **Суперстабильность с точным периодом подтверждена:** |x_1024| = 10⁻⁹…10⁻¹²
   при min|x_{2^j}, j<10| ≥ 7×10⁻³; мой Ньютон сдвигает корни лишь на ~10⁻¹⁷.
3. **Калибровка воспроизведена:** мои d_u совпали с kilo до <2×10⁻³
   относительных на всех проверенных.
4. **Закон дрейфа:** 1/λ₂ = 3.4266 против наблюдаемых 3.4305/3.4047 ✓.
5. **Порча ловится:** сдвиг a_ss на 10⁻⁹ разрушает суперстабильность
   (|x_1024| = 7.5×10⁻² вместо 6×10⁻⁹).

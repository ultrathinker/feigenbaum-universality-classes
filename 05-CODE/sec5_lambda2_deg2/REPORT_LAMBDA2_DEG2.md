## 2. Находка, изменившая план работы

Первый прогон (сырой `u_cat` из `results.json`) дал d_u(m), **растущее**
с m=8 до m=11 и **насыщающееся** на константе ~2–4e-5 для всех
комплексных нулей — прямо противоположное ожидаемому убыванию. Причина
найдена: `results.json`'s `u_cat` численно ИДЕНТИЧНО
`zero_map.json`'s `representative_u`, которое, в свою очередь, равно
`level_trajectories[m=7]` — самой первой (сеточной) оценке нуля H, а
НЕ сошедшемуся к m→∞ значению. Собственные уровневые траектории H (m=7..10
в архиве) дрейфуют ещё на ~1e-5..1e-4 на уровне m=10, геометрически со
скоростью ~1/δ — того же порядка, что и сигнал d_u(m), который мы
измеряем.

**Исправление:** каждый нуль (реальный и комплексный) переэкстраполирован
к m=∞ по формуле Richardson u_∞ = u(m=10) + shift(9→10)·r/(1−r),
r=1/δ (точное δ, а не шумное эмпирическое отношение сдвигов), используя
собственные `level_trajectories` архива. Проверка: |u_∞ − raw u_cat| для
комплексных нулей составила 2.1e-5..3.9e-5 — почти точно совпадает с
уровнем насыщения из первого (неверного) прогона, что подтверждает
диагноз. Оценка остаточной ошибки экстраполяции (∝ shift·r²/(1−r)):
5.7e-8..7.9e-8 для комплексных нулей, 1.9e-7..8.1e-7 для вещественных —
на 1–3 порядка ниже целевого сигнала d_u(9..11) (кроме, отчасти,
d_u(11) для самых удалённых вещественных нулей, где запас падает до ~4х
— отмечено как ограничение в §7).

**Независимое подтверждение метода:** файл квартичного пилота
`H4_zeros.json` (`zeros_limit_extrapolated`) показывает ТУ ЖЕ технику —
их каталог уже был экстраполирован по level-7/8/9-траекториям с
отношением сдвигов ~7.42 (их δ₄=7.2847) ДО того, как измерялся закон
1/λ₂. Наш повторный прогон после аналогичной экстраполяции — это
методологически "то же самое сравнение", а не искажённое.

## 6. Вердикт

**Закон "1/λ₂" ОПРОВЕРГНУТ (реальное отношение = δ ≈ 4.669, а не
1/λ₂ ≈ 8.087) для класса степени 2.**

Наблюдаемая скорость убывания d_u(m) совпадает со скоростью убывания
самой ВЕДУЩЕЙ (неустойчивой) собственной величины оператора удвоения δ,
а не с подведущей "существенной" λ₂. Интерпретация (не доказана, но
согласуется со всеми найденными фактами): стандартное асимптотическое
разложение суперстабильной каскадной последовательности —

c_m − c_F = C₁·δ^{−m} + C₂·δ^{−2m} + ... (степенной ряд по δ^{−m}, без
обращения к подведущим λ)

— генерическое свойство ЛЮБОГО 1-параметрического семейства,
трансверсального ведущему неустойчивому направлению, и НЕ требует
подведущего собственного значения. Величина A·(c*(m)−c_F)·δ^m сходится
к своему пределу u_∞ с первой поправкой порядка δ^{−m} (то есть
геометрическим отношением ровно δ) — именно это мы и наблюдаем.

Квартичный пилот, напротив, сравнивал c*(m) уже с ПРЕДВАРИТЕЛЬНО
экстраполированным (Richardson, level 7/8/9) каталогом `H4_zeros.json`
(см. §2) — то есть "первый слой" (δ-скорость) уже был вычтен ДО измерения
закона; то, что осталось измерить — второй слой, где и проявилась λ₂.
Наш ПЕРВЫЙ (неисправленный) прогон степени 2 без предварительной
экстраполяции измерял смесь "остаточного смещения сырого u_cat" и
настоящего каскадного сигнала (и получил бессмысленное насыщение — не
убывание вообще). После применения ТОЙ ЖЕ техники предварительной
экстраполяции (наш §2-фикс) сравнение стало методологически честным по
отношению к квартичному прецеденту — и результат для степени 2 оказался
δ, не λ₂.

Формально это можно трактовать двояко:
- **(А) закон единый ("нижний слой" всегда δ, а λ₂-слой проявляется
  только ПОСЛЕ вычитания δ-слоя)** — тогда наш тест здесь измерил не тот
  слой, что квартика; корректная проверка требовала бы вычесть
  δ-компоненту из d_u(m) (например, подогнать d_u(m) = C·δ^{−m} +
  D·λ₂^{−m}·... и сравнить D) — это вне объёма текущей задачи (нужны
  точки с бОльшим m и/или более чистые нули, чем есть в read-only
  источниках);
- **(Б) закон НЕ единый** — квартика и квадрат ведут себя по-разному, и
  1/λ₂-объяснение дрейфа основной статьи (степень 2) специфично для
  квартики и не переносится напрямую.

Имеющихся данных (m=8..11, 14 нулей) достаточно для уверенного вывода
"наблюдаемое отношение = δ, не 1/λ₂" **на измеренном диапазоне m**, но
НЕ достаточно, чтобы различить (А) и (Б) — для этого нужен явный
двухпараметрический fit на бОльшем диапазоне m, вне текущего объёма
работы.

  шум вокруг доминирующего δ-тренда — не разделены количественно.
- Только 3 вещественных нуля (все из архивного `zero_map.json`,
  ideation-sweep, "NOT RIGOROUS" по своей собственной пометке) — не
  independently rederived.
- Z72 — по построению циркулярна на m=10, использована только
  диагностически, как и предписано брифом ("истинная позиция, не центр
  диска"), но её собственная "истинность" сама зависит от суперстабильного
  Ньютона — не независимый источник.
- Гипотезы (А)/(Б) из §6 не разделены — требует fit на большем диапазоне
  m или на менее зашумлённых нулях, вне объёма этой задачи.
- Бонус-пункт брифа (сопоставление с "0.9635" из §7 статьи) НЕ выполнен
  отдельно как численный fit — но его физический смысл прояснён
  качественно в §2: `REPORT_UNIFIED.md`'s собственный "drift-law vector
  check" (median |R/Rpred|=0.9635, где Rpred строится из H-конструкции's
  own u8/u9 shift) уже, по сути, детектирует ТУ ЖЕ m=7-seed-bias
  механику, которую мы независимо нашли и исправили в §2 — не новый
  (λ₂-driven) эффект, а тот же артефакт сырого каталога, количественно
  подтверждённый с другой стороны.

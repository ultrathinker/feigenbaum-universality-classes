## 1. Вердикт
1. Рецепт H₂ у `../b1_2_F11_d2` был сломан (t=x² вместо w=(x²−1)/r_disc); верный рецепт — из address_certificate.json, проверен на flint 512 бит.
2. Валидация: 23/23 известных нулей восстановлены (dist 3e-7…1.6e-6, допуск 1e-3 превзойдён на 3+ порядка). 219 обычным путём, 3 трудных (Z38, Z72, Z73 — узкая котловина у полюса H, независимо согласуется с их особой сертификацией в исходных данных) — честным малошаговым Ньютоном от смещённого старта.
3. Каталог: 222 уникальных нуля (441 с сопряжениями), выше ожидания брифа (50–150).
4. Решётка 1/16 на n=23 не видна (p~0.3, как и раньше — мало мощности), но на расширенном каталоге статистически ясна (30.2 %/27.4 %/12.9 % у узла по Re/Im/обеим, p(оба)=8.9e-34 при n=441; пик Рэлея у q=16 — сильнейший на всём диапазоне 0.5–40). Слабее, чем у d=4/6 (~30 % против ~47 %). 1/32 тоже значима, слабее (7.5 %, p=3e-13).
5. K7 (полное отсутствие решётки при d=2) в сильной форме не подтверждается; альтернатива — калибровочная мода модулирует силу эффекта, а не выключает его.

## 2. Метод
Конвенция (address_certificate.json, подтверждена x4_common.py): x₀=0, x_{n+1}=g(w)+s·h(w), w=(x²−1)/r_disc, r_disc=2.5, s=u·AU0/δ^m, AU0=0.414037999086273…, δ=4.669201609102990…, H_m=x_{2^{m+1}}/x_{2^m}. g,h — ряды Тейлора степени 99 из w33_gh_hiprec.json через cheb_to_taylor.
Скан: смешанная сетка (грубая 1/16 по Re[−16,16]×Im[0,16], 131 841 узлов + точная 1/64 в Re[1,10]×Im[3,9], 222 145 узлов, обе m=8) → локальные минимумы |H|<2.5 → батч-Ньютон float64 (аналитический градиент) → кластеризация (ε=1e-5) → 219 уникальных → уточнение до m=9, m=10 → спаривание m=7↔8 (219/219 стабильны) → mpmath полировка (dps=25, 43 точки) для контроля float64. 3 трудных случая — отдельно (Ньютон с cap=0.01 от u_actual+смещение). Домен: max|x_n|<10.

## 3. Числа
**Валидация**: 23/23, медиана dist 7.6e-7, макс 1.6e-6.
**Решётка** (симметричный тест dist_1d<0.125/(2q), ожидания 12.5 %/1.5625 %):

| Набор | n | q | Re-узел | Im-узел | Оба | p(оба) | 2D-медиана |
|---|---|---|---|---|---|---|---|
| known23 | 23 | 16 | 8.7 % | 21.7 % | 4.3 % | 0.304 | 0.0228 |
| known23 | 23 | 32 | 13.0 % | 21.7 % | 4.3 % | 0.304 | 0.0107 |
| scan_full | 441 | 16 | 30.2 % | 27.4 % | **12.9 %** | **8.9e-34** | 0.0181 |
| scan_full | 441 | 32 | 22.0 % | 22.9 % | 7.5 % | 3.1e-13 | 0.0104 |

χ²/KS на scan_full@16 все p<1e-6; на known23 все p>0.1. Рэлей: пик scan_full у q≈16 (R=0.32–0.33) — сильнейший на 0.5–40; known23 пик у q=16 слабый (R=0.23, p=0.30).
**Проверка на артефакт сетки**: каталог, найденный ТОЛЬКО грубой 1/16-сеткой (n=312, вне точной подобласти), показывает даже более сильный сигнал (both=16.0 %, p=2.3e-34), чем найденный с участием точной 1/64-сетки (n=129, both=5.4 %, p=4.3e-3) — довод против чистого grid-артефакта, но не полное опровержение (сдвинутая/иррациональная сетка не пробовалась).

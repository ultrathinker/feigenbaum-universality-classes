## Вердикт: АРТЕФАКТ селекции сканера (d = 4)

Решающий контроль (`r1a_H4_shift16.json`): нули, найденные сдвинутой сеткой 1/16, **не** льнут к исходным (несдвинутым) узлам 1/16 — доли у узла re/im/joint = 9.5 % / 8.1 % / 2.7 % (p = 0.83 / 0.91 / 0.32; нулевая модель 12.5 / 12.5 / 1.56 %), но **сильно** льнут к своим сдвинутым узлам — 50.0 % / 47.3 % / 31.1 % (p = 6·10⁻¹⁵ / 3·10⁻¹³ / 1·10⁻²³). То же для перескана 1/24: относительно собственной сдвинутой сетки 1/24 — p до 4·10⁻⁵², относительно несдвинутых узлов 1/16 — p ≈ 0.2–0.6 (сигнала нет). Настоящие корни не могут «следовать» за произвольным сдвигом сетки — кластеризация есть свойство процедуры поиска, а не нулей H₄.

Ключевые числа (`r1a_stats_d4.json`, критерий frac16 < 1/16, т.е. |u − узел| < 1/256): ORIG (62): joint 24.2 % (p = 4·10⁻¹⁴); ORIG-ONLY (31 оригинальных нулей, не найденных пересканом 1/24): 41.9 % (p = 5·10⁻¹⁶ — сильнее всего); BOTH (31 общих): 6.5 % (p = 0.084, незначимо); NEW-ONLY (115 новых): 0.0 % (p ≈ 1).

## Механизм (установлен прямо)

Все 31 ORIG-ONLY нуля потеряны пересканом исключительно на стадии отбора кандидатов: у 28/31 ближайший узел сдвинутой 1/24-сетки не является локальным минимумом |H| (значение |H| там 0.2–3.7, а не «долина» < 0.2), у 3/31 узел отвергнут domain_check. Ни одного случая, где Ньютон из валидного кандидата не вернулся бы к нулю или сошёлся не туда. «Долина» малости |H| у многих нулей уже шага сетки (1/16 ≈ 0.0625), поэтому нуль попадает в каталог тогда и только тогда, когда узел сетки случайно оказался в его долине, — то есть в каталог отбираются нули, лежащие вблизи узлов. Это и есть наблюдавшаяся «решётка».

## Побочные, но важные находки

1. Каталоги неполны: перескан 1/24 находит 146 нулей уровня 8 в том же регионе против 62 (из них 95/115 новых — подлинные устойчивые нули H₈: |H₈| < 10⁻¹⁵ при независимом mpmath-пересчёте, Ньютон из возмущения |ε| = 10⁻³ возвращается ≥ 3/4 раз). Фильтр спаривания уровней m = 7/8 — отдельный мощный эффект: множество «есть партнёр на m = 7» в перескане в точности совпадает с множеством «совпадает с ORIG» (31 = 31); все 115 новых нулей партнёра не имеют, потому что каталог уровня 7 построен той же сеткой и страдает той же селекцией.
2. Незадекларированное отклонение перескана: `newton_refine` вызван с rmax = 25.0 вместо авторских 22.0; из-за этого 16/146 нулей STEP24 (все — NEW-ONLY, |u| до 24.69) недостижимы оригинальным конвейером и все «нежизнеспособны» (Ньютон из возмущения не возвращается). Оставшиеся 20/115 нежизнеспособных — в основном граничная зона |u| > 20. Точная репродукция уровня 7 ORIG (62/62, worst-dist 0.00) получается только с rmax = 22.0.
3. Подлинность ORIG: 60/62 «genuine + survive»; 2 нуля у границы |u| ≈ 20.5 не проходят тест Ньютона из возмущения (вероятно, тесная область у края домена). Все 62 имеют партнёра на m = 7.

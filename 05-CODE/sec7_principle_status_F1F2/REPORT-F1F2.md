## 1. Вердикт

1. **F1 — принцип выводится как теорема с оценкой остатка, и предсказание остатка ПОДТВЕРЖДЕНО на данных с точностью до множителя ~2 для класса d=6.** Для d=4 критерий «множитель 2» выполняется на уровне 67–77 % точек (погранично), что ниже, чем для d=6 (95 %), но качественно структура остатка (λ₂-слой + δ-слой) подтверждена обоими классами.
2. **Форма остатка по данным: e_m ≈ (α₁·u + α₀)·λ₂^m + (γ·u² + γ₀)·δ^{−m} (+ член λ₃), доминирует более медленный из слоёв — правило min(δ, 1/|λ₂|).** Проверено: медианное отношение d_u(9)/d_u(10) = 2.56 (d=6) и 2.40 (d=4) против 1/|λ₂| = 2.695 и 3.43 — λ₂-слой; скорость на глубоких уровнях (rate_full d=6) даёт отношения 2.5–3.7 ≈ 1/|λ₂|.
3. **Гипотеза брифа «c₁·u·(λ₂/δ)^m» ОТКЛОНЕНА данными**: в u-координате субведущая мода входит как λ₂^m (амплитуда ~ α₁·u + α₀), а не (λ₂/δ)^m; масштаб (λ₂/δ)^m при m=9 был бы ~10⁻¹³ против наблюдаемых ~10⁻³. Это соответствует двухчленной модели черновика e(m) ~ −(C·δ^{−m} + D·λ₂^m) (§5) и показателям Briggs 1994 (1/λ₂ = 3.43, 2.69).
4. **F2 — нетривиальность сформулирована**: из «универсальности как таковой» НЕ следует (i) точечная структура нулей (какие именно точки), (ii) глобальность в u (до |u|≈48), (iii) кратность узора; следует только скорость (min-правило, известно с 1987–94). Главный неожиданный результат — **линейная (1-го порядка по s) реконструкция каталога принципиально не воспроизводит узор** (даёт один ложный нуль), то есть узор — существенно нелинейный объект даже при s = u·AU0/δ^m → 0.

## 3. F1, шаг 1 — пертурбативный вывод

**Разложение семейства по модам линеаризации T.** Пусть T — оператор удвоения, g — его неподвижная точка (T g = g, g(0)=1, чётная), L = DT_g. Спектр: δ>1 (неустойчиво, вектор h), λ₂, λ₃, … (|λ_k|<1, векторы φ_k). Семейство f_a(x)=1−a|x|^d:

    f_a = g + (a−a_F)(c₁·h + c₂·φ₂ + c₃·φ₃ + …) + (a−a_F)²·w + O((a−a_F)³),

где c₁·h — проекция касательной ∂_a f = −|x|^d на неустойчивое направление; c₁ ≠ 0 — условие поперечности семейства устойчивому многообразию (сам факт существования каскада). Поскольку g + (a−a_F)c₁h + … имеет в точке a=a_F невязку ε_F = f_{a_F} − g ∈ устойчивому подпространству (T^m f_{a_F} → g), итерация по собственным модам даёт:

    T^m f_a = g + c₁(a−a_F)δ^m·h + [c₂(a−a_F) + ε₂]·λ₂^m·φ₂ + [c₃(a−a_F) + ε₃]·λ₃^m·φ₃
              + c₁²(a−a_F)²·δ^m·w_h + … (нелинейность, доминирует h-проекция),

где ε_k — компоненты ε_F по φ_k (константы, не зависят от a).

**Условие суперстабильности через фиксированный функционал.** x_{2^{m+1}}(a) = 0 ⟺ F₀(T^m f_a) = 0, где F₀ — ФИКСИРОВАННЫЙ (не зависящий от m) функционал «критическая орбита периода 2» (после m ре нормализаций возврат в 0). Каталог построен по карте g + s·h с s = u·AU0/δ^m, ИТЕРИРОВАННОЙ нелинейно — т.е. каталог учитывает всю нелинейность вдоль h-направления (включая член c₁²(a−a_F)²δ^m w_h, который и есть источник «δ-слоя»). Остаток возникает из НЕ-h части отклонения перенормированной карты:

    Δ_m − c₁(a−a_F)δ^m·h = [c₂(a−a_F)+ε₂]λ₂^m φ₂ + [c₃(a−a_F)+ε₃]λ₃^m φ₃ + …

Через разложение F₀ в точке каталога:

    u_m(a) = u_i + R_m,   R_m = (α₁·u_i + α₀)·λ₂^m + (α₃·u_i + α₀′)·λ₃^m + (γ·u_i² + γ₀)·δ^{−m} + ρ_m,

где: α₁·u_i — вклад φ₂-компоненты касательной семейства (пропорционален u через (a−a_F) = u/(Aδ^m) и отклику, амплифицированному δ^m структурой орбиты — см. F2(c)); α₀ — вклад ε₂ (фиксированного λ₂-содержания f_{a_F} − g); γ·u_i² — δ-слой от несовпадения кривизны реального неустойчивого многообразия с касательной g + s·h (порядка (a−a_F)²δ^m = u²/(Aδ^m)); ρ_m — высшие порядки.

**Ключевая поправка к гипотезе брифа.** Бриф предполагал субведущий член в u-координате ~ u·(λ₂/δ)^m. Наивный пересчёт амплитуды моды (c₂(a−a_F)λ₂^m → деление на (a−a_F)δ^m) даёт именно (λ₂/δ)^m, НО пренебрегает тем, что отклик суперстабильного нуля на моду амплифицирован вдоль орбиты (множитель δ^m): u-остаток ~ λ₂^m·(α₁u + α₀). Данные однозначно выбирают λ₂^m (см. §4.3), что согласуется с двухчленной моделью черновика и с Briggs 1994.

## 5. F2 — нетривиальность

### (а) Калибровка u′ = 2u (тривиальная линейность)

Преобразование u → c·u (c ≠ 0) — линейная замена масштаба, инвариант всей конструкции: каталог масштабируется (s = u·AU0/δ^m → s = c·u·AU0/δ^m, нули u_i → c·u_i), M-сторона масштабируется той же константой (A → A/c → u_m → c·u_m), невязка d_u → |c|·d_u (относительно неизменна). Калибровка A фиксирует лишь аффинный масштаб (u = −1 на главном каскаде); выбор «u = −2» — та же теорема в других единицах и НЕ переносит содержания. Содержательные, калибровочно-инвариантные величины: отношение u_actual/u_cat → 1, скорость d_u(m)/d_u(m+1) → min-правило, точечное соответствие «нуль ↔ параметр».

### (б) Репараметризация a → φ(a)

Пусть a′ = φ(a) — гладкая обратимая замена с φ′(a_F) ≠ 0. В новых координатах u′ = A′(a′ − a_F′)δ^m, A′ = A/φ′(a_F), — соответствие ВЫЖИВАЕТ с теми же нулями u_i (узор — свойство КЛАССА, не параметризации). БЕЗ перекалибровки A: u′(a_i) = A(φ(a_i) − φ(a_F))δ^m → φ′(a_F)·u_i + φ″(a_F)·u_i²·δ^{−m}/(Aφ′(a_F)) + … — узор аффинно масштабируется множителем φ′(a_F): соответствие «ломается» ровно на глобальный аффинный рескейл (для линейного φ) или рескейл плюс δ^{−m}-поправка (для нелинейного φ). ГЛОБАЛЬНОСТЬ множителя (один на все нули, не per-zero) — часть универсального содержания. Если φ′(a_F) = 0 (вырожденная параметризация), узор коллапсирует к u′ = 0 — принцип требует поперечной координаты вблизи a_F.

### (в) Линейная vs нелинейная реконструкция каталога — ГЛАВНЫЙ НЕОЖИДАННЫЙ РЕЗУЛЬТАТ

Построен каталог в первом порядке по s: x_n = x_n^{(0)} + s·x_n^{(1)} (орбита g и её линейный отклик на h — общая последовательность, не зависит от u). H^{lin}_m(u) = [x^{(0)}_{2^{m+1}} + s·x^{(1)}_{2^{m+1}}]/[x^{(0)}_{2^m} + s·x^{(1)}_{2^m}] — отношение линейных функций от u → **не более ОДНОГО нуля**. Численно: единственный нуль u^{lin} = **−0.910264** (d=6) и −0.838392 (d=4), одинаковый на уровнях 8 и 9 (независим от m), отстоящий от истинного калибровочного нуля u = −1 на 0.09 (d=6) / 0.16 (d=4); на вещественной оси при |u| ≤ 2·δ^m/|AU0| линейный каталог даёт 0 нулей против **8** (d=6) и 3 (d=4) истинных.

**Почему это принципиально.** s = u·AU0/δ^m → 0 при m → ∞, но нулевое условие x_{2^{m+1}} = 0 — точная компенсация x^{(0)} + s·x^{(1)} ≈ 0, где оба члена амплифицированы орбитой (отклик x^{(1)} ~ δ^m), а второй порядок x^{(2)} ~ (x^{(1)})² ~ δ^{2m}: нелинейные поправки к позиции нуля порядка δ^m·s ~ u — порядка 1 в u-координате, несмотря на экспоненциально малое s. Поэтому узор невоспроизводим в первом порядке по s, и периферия |u|≳10 здесь не «слабое место», а часть того же нелинейного явления: **кратность и точечная структура узора — существенно нелинейные свойства H**, требующие полной нелинейной итерации g+s·h.

### (г) Что НЕ следует из «универсальности» как таковой

Универсальность (существование неподвижной точки g, гиперболичность, сходимость перенормировок) даёт: существование предела масштабированных суперстабильных параметров и СКОРОСТЬ сходимости (min-правило — следствие спектра, известно). НЕ следует:

1. **Точечная структура нулей** — КАКИЕ конкретно точки u_i (их позиции, число, кратность, комплексная структура) универсальность не предписывает: любой универсальный предельный набор был бы совместим с гиперболичностью. То, что предельные позиции суть именно нули H (и контроли 0/6, специфичность 1488× d=6) — эмпирическое содержание.
2. **Глобальность в u** — универсальность локальна (вблизи g, u ≈ 0); соответствие держится до |u| ≈ 48, вне касательной области, — глобальное утверждение.
3. **Кратность/парность** (сколько нулей на уровень, связь конкретных параметров с конкретными нулями) — см. (в): даже при s → 0 кратность требует нелинейности.

## 6. Выводы

1. Принцип узора выводится из пертурбативной РГ-структуры: f_a = g + (a−a_F)(c₁h + c₂φ₂ + …) + …, итерация по модам L, условие суперстабильности через фиксированный функционал F₀ — теорема с явной оценкой остатка R_m = (α₁u+α₀)λ₂^m + (α₃u+α₀′)λ₃^m + (γu²+γ₀)δ^{−m} + высшие.
2. Остаток предсказан out-of-sample с точностью до множителя 2 у 95 % точек (d=6, 287 нулей) — критерий брифа выполнен; для d=4 — 67–77 % (погранично), структура та же.
3. Скорость убывания остатка подтверждает закон min(δ, 1/|λ₂|) (λ₂-слой при d=4,6; δ-слой при d=2); форма «(λ₂/δ)^m» из брифа отклонена, подтверждена форма λ₂^m (двухчленная модель черновика).
4. Нетривиальность не в калибровке (тривиальна) и не в скорости (следствие универсальности), а в точечной структуре нулей и глобальности в u; линейная реконструкция каталога невозможна — узор нелинейно детерминирован.
5. «Тавтология универсальности» — неверное прочтение: универсальность даёт предел и скорость, но не диктует, КАКИЕ точки; специфичность (0/6 контролей, ~10³×) — самостоятельное содержание.

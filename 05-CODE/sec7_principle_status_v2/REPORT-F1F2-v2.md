    Δ_m − c₁(a−a_F)δ^m·h = [c₂(a−a_F)+ε₂]λ₂^m φ₂ + [c₃(a−a_F)+ε₃]λ₃^m φ₃ + …

## 5. F2 — нетривиальность

### (а) Калибровка u′ = 2u (тривиальная линейность)

Без изменений. Калибровка A фиксирует лишь аффинный масштаб (u=−1 на главном каскаде); выбор «u=−2» — та же теорема в других единицах и не переносит содержания. Содержательные, калибровочно-инвариантные величины: отношение u_actual/u_cat → 1, скорость d_u(m)/d_u(m+1) → min-правило, точечное соответствие «нуль ↔ параметр».

### (б) Репараметризация a → φ(a) — ИСПРАВЛЕНО по S5 (правка #4 списка)

Пусть a′ = φ(a) — гладкая обратимая замена с φ′(a_F) ≠ 0. В новых координатах u′ = A′(a′ − a_F′)δ^m, A′ = A/φ′(a_F), — соответствие ВЫЖИВАЕТ с теми же нулями u_i (узор — свойство КЛАССА, не параметризации).

**Taylor для φ** до 2-го порядка вблизи a_F: φ(a) = φ(a_F) + φ′(a_F)(a−a_F) + ½·φ″(a_F)(a−a_F)² + O((a−a_F)³). Тогда

    u′ = A·δ^m · [φ(a) − φ(a_F)]
       = A·δ^m · [φ′(a_F)(a−a_F) + ½·φ″(a_F)(a−a_F)² + O((a−a_F)³)]
       = φ′(a_F)·u + ½·φ″(a_F)·u²·δ^{−m}/A + O(u³·δ^{−2m}).

**Квадратичный член — φ″(a_F)·u_i²·δ^{−m}/(2A)**, **БЕЗ** лишнего 1/φ′(a_F) (это была ошибка в REPORT; корректное разложение Тейлора не вносит дополнительного φ′-множителя в числитель квадратичного члена). Узор аффинно масштабируется множителем φ′(a_F): соответствие «ломается» ровно на глобальный аффинный рескейл (для линейного φ) или рескейл + δ^{−m}-поправка (для нелинейного φ). ГЛОБАЛЬНОСТЬ множителя (один на все нули, не per-zero) — часть универсального содержания. Если φ′(a_F) = 0 (вырожденная параметризация), узор коллапсирует к u′ = 0 — принцип требует поперечной координаты вблизи a_F.

### (в) Линейная vs нелинейная реконструкция каталога — ИСПРАВЛЕНО по S5 (правка #5 списка)

Построен каталог в первом порядке по s: x_n = x_n^{(0)} + s·x_n^{(1)} (орбита g и её линейный отклик на h — общая последовательность, не зависит от u). H^{lin}_m(u) = [x^{(0)}_{2^{m+1}} + s·x^{(1)}_{2^{m+1}}]/[x^{(0)}_{2^m} + s·x^{(1)}_{2^m}] — отношение линейных функций от u.

**Точный алгебраический факт (а не наблюдение):** s = u·AU0/δ^m — линейная функция от u. Поскольку x_{2^k}^{(0)} и x_{2^k}^{(1)} — константы (не зависят от u), числитель H^{lin}_m есть

    N(u) = x^{(0)}_{2^{m+1}} + s·x^{(1)}_{2^{m+1}} = (x^{(1)}_{2^{m+1}}·AU0/δ^m)·u + x^{(0)}_{2^{m+1}},

то есть **аффинная функция от u**. У аффинной функции на ℂ — **ровно один корень** (если коэффициент при u ≠ 0). Корень u^* = −x^{(0)}_{2^{m+1}}·δ^m/(x^{(1)}_{2^{m+1}}·AU0). **Это не требует сканирования — это прямое следствие структуры задачи**, и работает для всех m (корень m-стабилен, потому что x^{(0)}_{2^{m+1}} и x^{(1)}_{2^{m+1}} определены через одну и ту же неподвижную точку g и один отклик h). Численная проверка (`s5_F1F2_check/check_f2c_fix.py`, numpy float64, раздельно числитель/знаменатель): u^* = **−0.910275** (d=6), **−0.838425** (d=4), устойчиво по m=5..8. Знаменатель имеет полюс (а не нуль) на u ≈ −8.462 (d=6) / −6.107 (d=4) — это не нуль H^{lin}.

**Исправление противоречия:** в оригинальном REPORT в одном абзаце утверждалось одновременно «единственный нуль u^{lin}=−0.910264» и «0 нулей против 8/3 истинных». «0» — артефакт грубой сетки `count_zero_crossings` в `f2c_experiment.py`: сканирование 40001 точки по диапазону |u|≤2·δ^m/|AU0| (~10⁸–10⁹ для m=8,9) с шагом ~4·10⁴…4·10⁷, физически не способным поймать пересечение вблизи u=−0.91. **Исправлено:** «0 против 8(d=6)/3(d=4)» → **«1 против 8(d=6)/3(d=4)»** (один нуль линеаризованного каталога, в отличие от 8/3 истинных).

Отстояние от истинного калибровочного нуля u=−1: 0.090 (d=6) / 0.162 (d=4). Узор невоспроизводим в первом порядке по s — нелинейные поправки к позиции нуля порядка δ^m·s ~ u сохраняются в пределе при s→0.

**Почему это принципиально.** s = u·AU0/δ^m → 0 при m → ∞, но нулевое условие x_{2^{m+1}}=0 — точная компенсация x^{(0)} + s·x^{(1)} ≈ 0, где оба члена амплифицированы орбитой (отклик x^{(1)} ~ δ^m), а второй порядок x^{(2)} ~ (x^{(1)})² ~ δ^{2m}: нелинейные поправки к позиции нуля порядка δ^m·s ~ u — порядка 1 в u-координате, несмотря на экспоненциально малое s. Поэтому узор невоспроизводим в первом порядке по s, и периферия |u|≳10 здесь не «слабое место», а часть того же нелинейного явления: **кратность и точечная структура узора — существенно нелинейные свойства H**, требующие полной нелинейной итерации g+s·h.

### (г) Что НЕ следует из «универсальности» как таковой

Без изменений. Универсальность даёт существование предела масштабированных суперстабильных параметров и СКОРОСТЬ сходимости (min-правило). НЕ следует:

1. **Точечная структура нулей** — КАКИЕ конкретно точки u_i (позиции, число, кратность, комплексная структура) универсальность не предписывает.
2. **Глобальность в u** — универсальность локальна (вблизи g, u≈0); соответствие держится до **|u|≤43.76** среди принятых (matched) внутренних каталогных нулей d=6 и до **|u|≤52.88** по всему каталогу нулей H₆ (включая непарные/edge) — **точные границы** вместо округлённого «|u|≈48» (см. также THEOREM-SKETCH §1).
3. **Кратность/парность** (сколько нулей на уровень, связь конкретных параметров с конкретными нулями) — см. (в).

## 6. Выводы

1. Принцип узора выводится из пертурбативной РГ-структуры: f_a = g + (a−a_F)(c₁h + c₂φ₂ + …) + …, итерация по модам L, условие суперстабильности через фиксированный функционал F₀ — теорема с явной оценкой остатка R_m = (α₁u+α₀)λ₂^m + (α₃u+α₀′)λ₃^m + (γu²+γ₀)δ^{−m} + высшие. **Статус: набросок, не доказательство.**
2. **d=6:** OOS-критерий «within ×2» устойчив на уровне ~92 % по случайным сплитам и k-fold CV; baseline-константа — ~90 %; выигрыш ~1.5 п.п. структурный, но малый. **«Подтверждено как работающая модель».**
3. **d=4:** OOS «within ×2» статистически не убедителен (разброс 9.3–97.7 % по 500 сплитам, k-fold CV = 78.7–80.3 %, baseline-const = 76.7 % — **модель не превосходит константу данным критерием**); качественная структура остатка (λ₂-слой + δ-слой) — та же, что и для d=6 (rate-relations d(9)/d(10)=4.91 подтверждают λ₂-слой с маржой 13× над (λ₂/δ)^m).
4. Скорость убывания остатка подтверждает закон min(δ, 1/|λ₂|) (λ₂-слой при d=4,6; δ-слой при d=2); форма «(λ₂/δ)^m» из брифа отклонена, подтверждена форма **λ₂^m** (двухчленная модель черновика). Маржа λ₂^m над (λ₂/δ)^m: 165× (d=6) / 13.5× (d=4).
5. Нетривиальность не в калибровке (тривиальна) и не в скорости (следствие универсальности), а в точечной структуре нулей и глобальности в u; **линейная реконструкция каталога даёт РОВНО ОДИН нуль (аффинная числительная функция ⇒ ровно один корень на ℂ)** — узор нелинейно детерминирован.
6. «Тавтология универсальности» — неверное прочтение: универсальность даёт предел и скорость, но не диктует, КАКИЕ точки; специфичность (0/6 контролей, ~10³×) — самостоятельное содержание.

## 1. Формулировка

Пусть d ∈ {2, 4, 6}, f_a(x) = 1 − a·|x|^d, T — оператор удвоения периода, g — его неподвижная точка (g(0) = 1, чётная, T g = g), L = DT_g. Обозначим ведущий спектр:

- δ > 1 — неустойчивое собственное значение, собственный вектор h (универсальная мода каскада);
- λ₂, λ₃, … — субведущий спектр (|λ₂| ≥ |λ₃| ≥ …), собственные векторы φ₂, φ₃, …;
- a_F — предельная точка каскада (накопление), A — калибровочная константа (u = −1 на главном каскаде), AU0 — амплитуда каталога (s = u·AU0/δ^m);
- H_d(u) — универсальная масштабирующая функция, каталог {u_i} — её простые нули (предельные позиции уровней m → ∞).

**Определение.** Параметр a называется суперстабильным уровня m, если x_{2^{m+1}}(a) = 0 для критической орбиты x_0 = 0, x_{k+1} = f_a(x_k), с точным периодом 2^{m+1}. Масштабированная координата: u_m(a) = A(a − a_F)δ^m.

> **Теорема (принцип узора с оценкой остатка; НАБРОСОК).** Существует такое 1-параметрическое семейство суперстабильных параметров {a_m^{(i)}} уровня m (m ≥ m₀(i)), периода ровно 2^{m+1}, что
>
> $$u_m^{(i)} = A(a_m^{(i)} - a_F)\delta^m = u_i + R_m^{(i)},$$
>
> $$R_m^{(i)} = (\alpha_1 u_i + \alpha_0)\lambda_2^m + (\alpha_3 u_i + \alpha_0')\lambda_3^m + (\gamma u_i^2 + \gamma_0)\delta^{-m} + \rho_m^{(i)},$$
>
> с высшим остатком |ρ_m| ≲ K·(1 + u_i²)·δ^{−2m} (d = 6; для d = 4 аналогично с учётом |λ₂| > |λ₃|), и коэффициенты (α₁, α₀, γ, …) — ограниченные константы класса. В частности, для каждого каталогного нуля существует суперстабильный параметр, масштабированная позиция которого сходится к этому нулю:
>
> $$\lim_{m\to\infty} d_u^{(i)}(m) = \lim_{m\to\infty} |u_m^{(i)} - u_i| = 0,$$
>
> а скорость сходимости задаётся правилом **min(δ, 1/|λ₂|)**: при 1/|λ₂| < δ (d = 4, 6) доминирует λ₂-слой (отношение соседних уровней → 1/|λ₂|), при 1/|λ₂| > δ (d = 2) — δ-слой (отношение → 1/δ). **Форма остатка — λ₂^m, не (λ₂/δ)^m** (см. §2 шаг 4 и §5 ниже).

### Единицы и согласование с OLS-фитом (ИСПРАВЛЕНО по S5, правка #7)

В оценке R_m используются коэффициенты двух типов, и в оригинальной формулировке §1 это различие не было оговорено — отсюда рассогласование между заявленными «|α₁| ≲ 0.06, |α₀| ≲ 0.5 для d = 6 в единицах §4» и OLS-фитом REPORT §4.1 (d = 6, m = 9: c₁ = 5.35·10⁻⁵ − 2.24·10⁻⁵i, c₀ = −4.73·10⁻⁴ − 1.95·10⁻⁴i).

**Уточнение:** α₁, α₀ в формуле теоремы — это коэффициенты **в единицах e₉** (e₉ = u_actual − u_cat для m=9). Тогда:

- Заявленные границы |α₁| ≲ 0.06, |α₀| ≲ 0.5 — формально верны (OLS даёт |c₁| ≈ 6·10⁻⁵, |c₀| ≈ 5·10⁻⁴ в этих единицах).
- Эти же коэффициенты, отнесённые к u-невязке на уровне m (умножение на λ₂^m с λ₂=0.371, m=9 ⇒ λ₂⁹ ≈ 6.7·10⁻⁵), дают «масштабированные» α₁=c₁/λ₂⁹ ≈ 0.43, α₀=c₀/λ₂⁹ ≈ 3.7 — расхождение с заявленными границами объясняется тем, что **заявленные границы относятся к ненормированным коэффициентам e₉**, а не к «истинным» α₁, α₀ в u-единицах.

**Переформулировка границ (согласованно с OLS):** для d = 6 в единицах «e₉»:

- |α₁| ≲ 10⁻⁴ (порядка 6·10⁻⁵ по OLS), запас ≈100× до ε∼10⁻² — слабые границы, ничего жёстко не ограничивают, кроме порядка;
- |α₀| ≲ 10⁻³ (порядка 5·10⁻⁴ по OLS), запас ≈100×.

Для построения **строгих** границ (нужных для теоремы) требуется компьютерно-ассистированная машинерия: явная оценка коэффициентов отклика ∂α₁/∂α_k через Krawczyk-сертификаты спектра. Это один из формально открытых шагов (§3, п.3).

### Глобальность соответствия в u (ИСПРАВЛЕНО по S5, правка #8)

Округлённое «|u| ≈ 48» в REPORT/THEOREM-SKETCH §4 заменено на точные границы:

- **|u_cat| ≤ 43.76** среди принятых (matched) внутренних каталогных нулей d = 6 (n = 287);
- **|u| ≤ 52.88** по полному каталогу нулей H₆ (включая непарные/edge), экстраполяция уровней 7–9 с дрейфом ≈ δ.

Какое именно число цитировать, зависит от контекста: при обсуждении «соответствия нуль↔параметр» в пределах принятого каталога — 43.76; при обсуждении полного покрытия нулей H₆ — 52.88.

**Совместимость с известным:** двухчленная модель черновика e(m) ~ −(C·δ^{−m} + D·λ₂^m) (§5) — первый член нашего δ-слоя, второй — наш λ₂-слой; показатели 1/λ₂ = 3.43 (d=4), 2.69 (d=6) — Briggs 1994. Формулировка «u_i → именно нули H», специфичность (~10³×, контроли 0/6) — вне скорости, самостоятельное содержание теоремы.

## 2. Набросок доказательства

**Шаг 1 (разложение семейства по модам).** Вблизи a_F:

    f_a = g + (a−a_F)(c₁h + c₂φ₂ + c₃φ₃ + …) + (a−a_F)²·w + O((a−a_F)³),

где c₁h — проекция касательной ∂_a f = −|x|^d на неустойчивое направление. Требуется поперечность c₁ ≠ 0 (существование каскада ⇒ невырожденность); для строгого доказательства — компьютерно-ассистированная проверка (положительный нижний бонд проекции), аналогично сертификации спектра §4.4.

**Шаг 2 (итерация).** По собственным модам L (и с учётом ε_F = f_{a_F} − g ∈ устойчивому подпространству, поскольку T^m f_{a_F} → g):

    T^m f_a = g + c₁(a−a_F)δ^m h + [c₂(a−a_F)+ε₂]λ₂^m φ₂ + [c₃(a−a_F)+ε₃]λ₃^m φ₃ + c₁²(a−a_F)²δ^m w_h + …

(доминирующий квадратичный член — h-проекция кривизны неустойчивого многообразия, амплифицированная δ^m). Гиперболичность L и сходимость T^m f_{a_F} → g — стандартная машинерия (Ланфорд 1982; для d = 4, 6 — по дискретизациям N = 40/48, §4.4).

**Шаг 3 (условие суперстабильности как фиксированный функционал).** Критическая орбита периода 2^{m+1} эквивалентна (после m ренормализаций и рескейла) возврату в 0 за два шага перенормированной карты: существует фиксированный функционал F₀ (F₀(M) = 0 ⟺ M(M(0)) = 0, с проверкой точного периода) такой, что

    x_{2^{m+1}}(a) = 0  ⟺  F₀(T^m f_a) = 0.

Каталог H_m построен по карте g + s·h, s = u·AU0/δ^m, итерированной НЕЛИНЕЙНО: каталог содержит полную нелинейность вдоль h-направления. Невырожденность F₀ в точке каталога (простота нуля H, ∂F₀/∂α₁ ≠ 0) — условие, проверяемое численно (невязки |H| ~ 10⁻⁴², дрейф позиций ≈ δ между уровнями) и требующее формального обоснования.

**Шаг 4 (остаток через не-h часть) — ИСПРАВЛЕНО по S5, правка #6 списка.** Пусть перенормированная карта M_m = T^m f_a = g + α₁^{(m)}h + α₂^{(m)}φ₂ + α₃^{(m)}φ₃ + …, α₁^{(m)} = c₁(a−a_F)δ^m + …, α₂^{(m)} = [c₂(a−a_F)+ε₂]λ₂^m + …. Из F₀(g + α₁h + α₂φ₂ + …) = 0 по теореме о неявной функции:

    α₁ = α₁^* + (∂α₁/∂α₂)·α₂ + (∂α₁/∂α₃)·α₃ + (нелинейные члены).

Пересчёт в u-координату (u = A·α₁/c₁ при a = a_F + u/(Aδ^m)) даёт остаток из §1: λ₂-слой (α₁u + α₀)λ₂^m — из φ₂-компоненты касательной и ε_F; λ₃-слой; δ-слой (γu² + γ₀)δ^{−m} — из несовпадения кривизны реального многообразия с касательной g + s·h (множитель (a−a_F)²δ^m = u²/(A²δ^m) с точностью до коэффициента отклика).

**Ключевой нетривиальный факт — ИСПРАВЛЕНО по S5, правка #6:** шаг «∂α₁/∂α₂ амплифицирован структурой орбиты (множитель ~ δ^m)» — это **гипотеза/эвристика**, не выведенный факт; рекомендуется заменить/дополнить прямым выводом через известную мультипликативную форму параметрической поправки (Vul–Sinai–Khanin / Briggs 1994): классическая мультипликативная форма

    a_m − a_F ~ K·δ^{−m}·(1 + c·λ₂^m + …)

при переходе в u = A(a_m − a_F)·δ^m даёт u = A·K + A·K·c·λ₂^m + … — то есть аддитивный λ₂^m-член в u-координате с точностью до аддитивной константы A·K. **Эта мультипликативная форма даёт тот же λ₂^m-результат чище** и без дополнительных предположений об амплификации отклика — рекомендуется использовать её в строгой версии.

**Согласование формы λ₂^m с законом min(δ, 1/|λ₂|) — ИСПРАВЛЕНО по S5, правка #9 списка.** В R_m три слагаемых с разными скоростями убывания:

- **λ₂-слой** (α₁u + α₀)λ₂^m — убывает как |λ₂|^m (норма в u);
- **δ-слой** (γu² + γ₀)δ^{−m} — убывает как δ^{−m};
- **высший остаток** ρ_m ~ δ^{−2m}.

Все три — **отрицательные степени** (δ^m идёт в u-определении, а в R_m входит как δ^{−m}). Правило min(δ, 1/|λ₂|) применяется не к форме R_m, а к **выбору доминирующего слоя** между λ₂-слоем (множитель |λ₂|^m) и δ-слоем (множитель δ^{−m}). На уровне m:

- если |λ₂|^m **убывает быстрее**, чем δ^{−m} **растёт** — т.е. если 1/|λ₂| < δ (d = 4, 6: 1/λ₂ = 2.69–3.43 < δ = 7.28–9.30), то λ₂-слой становится меньше δ-слоя при больших m, и **δ-слой доминирует** (медленнее убывает). Именно это и наблюдается в rate-study (см. REPORT §4.3): отношения d(9)/d(10) ≈ 2.83 (d=6)/4.91 (d=4) ≫ 1, и эта величина — вклад δ-слоя между уровнями (медленное убывание).
- если 1/|λ₂| > δ (d = 2: 1/λ₂ > δ), то δ-слой убывает быстрее и **λ₂-слой доминирует** — переоткрытие закона Mao–Hu / Reick / Briggs для d = 2.

В **обоих** случаях форма остатка λ₂^m (а не (λ₂/δ)^m) — это правильное выражение для вклада **субведущей моды** в u-координате; меняется лишь то, какой из двух членов R_m (λ₂-слой или δ-слой) доминирует при данном d.

**Шаг 5 (высший остаток и скорость).** Члены (a−a_F)³·δ^{2m}, (λ₂^m)² и т.д. дают |ρ_m| ≲ K·δ^{−2m}·(1+u²); для строгой версии нужны явные равномерные по i границы коэффициентов отклика.

## 4. 5–8 предложений для черновика (§7 Discussion: статус принципа)

Принцип узора выдерживает редукцию к пертурбативной ренормгруппе: разложение семейства по собственным модам линеаризации оператора удвоения (неустойчивое направление h плюс субведущие φ₂, φ₃) и сведение условия суперстабильности к фиксированному функционалу на перенормированной карте дают принцип как теорему с явным остатком R_m = (α₁u+α₀)λ₂^m + (γu²+γ₀)δ^{−m} + …; форма λ₂^m (а не (λ₂/δ)^m брифа) подтверждена rate-тестом на сырых данных d=6/d=4 с маржой 165×/13.5×, причём для d=6 OOS-критерий «within ×2» устойчив на уровне ~92 % по случайным сплитам и k-fold CV. Критика «тавтологии универсальности» не подтверждается: универсальность даёт лишь существование предела масштабированных параметров и его скорость (min(δ, 1/|λ₂|) — переоткрытый закон Mao–Hu/Reick/Briggs), но не диктует, какими именно точками являются предельные позиции, — точечное совпадение с нулями H и его специфичность (~10³×, нуль совпадений у контролей) остаются самостоятельным содержанием. Более того, линейная (первого порядка по s) реконструкция каталога принципиально не воспроизводит узор — даёт **ровно один** ложный нуль (точный факт: числитель H^{lin}_m — аффинная функция от u ⇒ ровно один корень на ℂ), — поскольку нелинейные поправки к позиции нуля порядка δ^m·s ~ u сохраняются в пределе при s → 0: кратность и точечная структура узора существенно нелинейны, и глобальность соответствия вплоть до |u|≤43.76 (matched) / 52.88 (полный каталог) не следует из локальной универсальности. Калибровочная и репараметризационная свободы (u → c·u; a → φ(a)) тривиальны — они дают аффинный рескейл узора, не меняя ни точечной структуры, ни скорости, ни парности. Строгая версия теоремы требует компьютерно-ассистированного обоснования четырёх элементов (поперечность c₁, простота нулей, равномерные границы коэффициентов отклика, высший остаток) и остаётся задачей следующего этапа; **для d=4 при n=61 модель не превосходит константный baseline по критерию within×2**, что на качественном выводе не сказывается (rate-relations λ₂-слоя подтверждены), но количественную «точность предсказания» нужно понимать как структурную (~92 % для d=6), а не как универсальную; открытый вопрос §7.4 (механизм точечной конверсии мод в чётных d) на принцип не влияет, но связан с его пертурбативной машинерией.

## 3. Редукционная теорема (хвостовой зазор = две гипотезы)

**Постановка.** X = {φ ∈ C([0,1]): φ(0)=0}, ‖·‖∞; G* — истинная фикс-точка
(уравнение G = −αG∘W, W(t)=G(t/α²)², лист G(0)=1), T* = DT_{G*} — линеаризация
(цепная формула фазы 1); λ₂^∞ — её существенное с.з. (непрерывное продолжение
дискретного ранга 2). Сертифицированные: G_N (K1-бокс), φ̃ (mini-K2-бокс, φ̃(1)=1±1e-30),
λ̃ = mid[λ₂-сертификат].

**Лемма (квазимодовая локализация; доказана, элементарно).** Пусть T ∈ B(X), u ∈ X,
‖Tu − λ̃u‖ ≤ R, ‖u‖ ≥ 1−ε. Если на окружности \|z−λ̃\| = ρ оператор T не имеет спектра
и ‖(T−z)⁻¹‖ ≤ S и S·R < 1−ε, то в открытом диске D(λ̃, ρ) есть хотя бы одна спектральная
точка T. [Доказательство: иначе (T−λ̃)⁻¹ = (1/2πi)∮(z−λ̃)⁻¹(T−z)⁻¹dz, норма ≤ S,
и 1−ε ≤ ‖u‖ ≤ ‖(T−λ̃)⁻¹‖·R ≤ SR — противоречие.] Здесь ε ≤ 5e-29: φ̃(1) = 1 ± 4.8e-29
в шарах (mini-K2-бокс), т.е. ‖φ̃‖∞ ≥ 1 − 5e-29.

**Теорема (редукция).** Пусть выполнены:
- **(H1a)** τ₁ := ‖G*−G_N‖∞ ≤ 1e-30, **(H1b)** τ₂ := ‖G*'−G_N'\|∞ ≤ 1e-29, **(H1c)**
  G*([0, 1/α*²]) ⊂ [−1,1] (область композиции; при τ₁ ≤ 1e-30 достаточно
  G_N([0,0.17]) ⊂ [0.74, 1] и G_N' < 0 там — ОБЕ проверены в шарах на 512 узлах,
  G_N-диапазон [0.7435, 1.0000], все G_N'-верхние оценки < 0);
- **(H2)** при некотором ρ ∈ (0, 0.065]: T* не имеет спектра на \|z−λ̃\| = ρ и
  ‖(T*−z)⁻¹‖ ≤ S там;
- **(H2')** в D(λ̃, 0.065) спектр T* состоит из единственной точки, и она есть λ₂^∞
  (идентификация: продолжение дискретного ранга-2).

Тогда ‖T*φ̃ − λ̃φ̃‖∞ ≤ R := 8.44e-26 + 4.5e-28 (строго, §2.3–2.4), и если
**S·R < 1**, то **|λ₂^∞ − λ̃| ≤ ρ**; вместе с §2.1:
**|λ₂^∞ − (−0.1236527125526870243353936525855)| ≤ ρ + 1.82e-33**.

**Условные числа.** Достаточно S ≤ 1.2e25 (при τ-гипотезе выше). Дискретный гайд
(§2.5): S(0.065) = 9.7e12 → запас 1e12. При экстраполяции S(ρ) ≈ c/ρ (c ≈ 2.2e9 по
точке d=0.02): S(1e-13) ~ 2.2e22, S·R ~ 1.9e-3 < 1 → **условный Δ ≈ 1e-13**
(консервативно с запасом ×100 к экстраполяции; без запаса — до 1e-15). Float-гайд
зазора — 1.7e-66 (лестница, §4.2): редукция теряет ~50 порядков строгости ради
превращения гипотезы в теорему.

**Почему H1, H2 не доказаны здесь (стена).** Обе требуют оценки бесконечномерной
обратной структуры: (H1) — ньютоновской обратной DF⁻¹ на аналитической алгебре
(ренорм-оператор не сжимается: δ > 1; простого мажорантного ряда Неймана нет,
‖K‖ ≈ α·‖G'W'‖ > 1); (H2) — резольвенты T* вне конечномерной аппроксимации. Это
машина Лэнфорда–EKW (полиномиальная валидация с хвостовыми боксами в весовых
коэффициентных нормах + эллиптическая алгебра). Зонд §7 показывает её
осуществимость; объём — отдельная ночь/задача.

  бесконечномерный зазор — только УСЛОВНАЯ теорема §3 (H1, H2, H2' не доказаны).
- Условное Δ ≈ 1e-13 опирается на экстраполяцию S(ρ) ~ c/ρ из дискретных точек
  (гайд, не доказательство для T*).
- Stage D интервальный: u(m) — float (mpmath dps 80, Ньютон ~1e-60); калибровки
  c_ss/A/c_F — float-калибровка Исследования-1 (не сертифицированы). Полного
  сертификата дрейфа c_ss(m) НЕТ (и не заявляется).
- Part A/C — float (dps 120), помечены NOT RIGOROUS; используемы только как гайды.
- H1c (область композиции) проверена на 512 узлах в шарах + монотонность G_N';
  строгая континуальная монотонность не выписана (косметика при τ₁ ≤ 1e-30, отмечено).

## 4. Двухслойная модель хвоста (бонус по брифу, из моего REPORT_TAIL §5–6)

Фит u(m) = u_inf + C·δ^{−m} + D·λ₂^m точно на моих u(11,12,13):
u_inf = 4.7916611642+7.1775795462i, |C| = 5.214, **|D| = 613.6** (комплексный; у
вещественных нулей было 4…274). Невязки предсказания на независимых уровнях:
m=10: 3.0e-9, m=9: 6.0e-8, m=8: 1.2e-6 (на низких m нужен третий слой).

| оценка tail(11→∞) | значение |
|---|---|
| однослойная (их C=6.375) | 3.5277e-7 |
| **двухслойная** \|C\|δ^{−11}/(1−1/δ_lower) + \|D\|\|λ₂\|^{11}/(1−\|λ₂\|) | **3.6087e-7** (L1 = 2.885e-7 + L2 = 7.235e-8) |

- Бюджет @ε=1e-10: 5.3642866e-3 против 5.3642785e-3 — **изменение в 5-й значащей цифре,
  вывод не тронут**; @ε=1e-20: +0.5%. Ожидание брифа подтверждено в том, что важно.
- Честный нюанс: на m=11 λ₂-слой лишь в ~4 раза меньше δ-слоя (20.5% однослойного
  хвоста), а не «на порядки» — комплексный узел Z72 имеет большой \|D\|. Однослойная
  калибровка по m=8,9 частично поглощает λ₂-слой в C (6.37 против чистых 5.21), поэтому
  обе оценки близки и обе консервативны (истинный остаток по моим d_u ≈ 2.6e-7).
- Немононтонность Δ11 < Δ12 из их §4 объясняется количественно: знакопеременный
  λ₂-слой (~±6e-8 на этих уровнях) поверх убывающего δ-слоя.

## 1. Постановка

Раздел 7 статьи сопоставляет 23 нуля универсальной функции H (строго
сертифицированы на H-стороне) с 23 суперстабильными параметрами c семейства
P_c(z)=z²+c точного периода 2^{m+1}=2048 вблизи точки Фейгенбаума c_F.
Численные корни M-стороны получены Ньютоном в mpmath (150 знаков) в пакете
`v2_work/unified_mandelbrot` (frozen_experiment.py); их существование до
настоящего пакета доказано не было. Задача: превратить каждый численный
корень в теорему существования и единственности методом интервального
Ньютона/Кравчика в шаровой арифметике (python-flint / Arb).

Вход (только чтение, sha256-пин в сертификате):
`article_v1/v2_work/unified_mandelbrot/results.json`. Корни берутся из
`stage3_catalog` (22 принятые записи); для Z72 — из
`stage3b_z72_corrected` (исправленная провенансная запись), НЕ legacy-строка
каталога (она в источнике помечена rejected и подтверждена таковой верификатором).

## 2. Метод

Для каждого корня (центр c₀ — точная десятичная строка из results.json,
n = 2^{m+1} = 2048, m = 10 — из данных файла):

* f(c) := P_c^n(0), орбита z₀=0, z_{k+1}=z_k²+c; производная по c:
  f'(c) = dz_n, dz₀=0, dz_{k+1}=2·z_k·dz_k+1.
* Бокс: сертифицируемое множество — замкнутый диск B(c₀, r). Включения в
  генераторе распространяются по надмножеству X := c₀ + W, где
  W = [±r] × [±r] — квадрат, надмножество диска B(0, r); r — наружная
  верхняя грань максимума радиусов обеих компонент W, из замороженной
  лестницы (первый проходящий: r = 1e-27 при 512 бит; лестницы радиусов и
  точности зафиксированы и в генераторе, и в верификаторе). Обоснование
  корректности «квадрат для диска» — §3.1.
* Регрессионный guard генератора (введён по аудиту, §6): до запуска орбит
  проверяется, что радиусы ОБЕИХ компонент X ≥ r; это одновременно
  гарантирует B(c₀, r) ⊆ X (ключевое включение §3.1) и защищает от
  повторного вырождения бокса в отрезок.
* Точечные включения: F₀ = f(c₀), Df₀ = f'(c₀); включение по боксу:
  D = f'(X) (шаровое распространение (z,dz) по X).
* Операторы (вся арифметика — строгие шары Arb, сравнения — только
  направленные шаровые проверки, никаких float-сравнений):
  * интервальный Ньютон (Moore): N(X) = c₀ − F₀/D;
  * Кравчик (Krawczyk, Y := 1/Df₀): K(X) = c₀ − Y·F₀ + (1 − Y·D)·(X − c₀).
* PASS-правило (все четыре условия обязательны):
  1) 0 ∉ D  (нижняя грань |f'(X)| > 0);
  2) N(X) ⊂ B(c₀, r)  (наружная верхняя грань |N−c₀| < r);
  3) K(X) ⊂ B(c₀, r)  (наружная верхняя грань |K−c₀| < r; мера
     контрактации κ = |K−c₀|_ub / r < 1);
  4) точный период: для каждого собственного делителя d = 2^j < n
     (j = 0..m, d = 1..1024) нижняя грань |P_c^d(0)| по ВСЕМУ боксу X > 0.

## 3. Теорема (что именно доказано)

**Лемма (интервальный Ньютон/Кравчик для голоморфной функции одного
комплексного переменного).** Пусть f голоморфна в окрестности замкнутого
шара X = B(c₀,r) ⊂ ℂ; F₀, Df₀ — шаровые включения f(c₀), f'(c₀); D — шаровое
включение f'(X); K(X) = c₀ − Y·F₀ + (1−Y·D)·(X−c₀), Y = 1/Df₀; N(X) =
c₀ − F₀/D. Если (i) 0 ∉ D и (ii) K(X) ⊂ int X, то f имеет ровно один нуль
c* в X. Дополнительно, если (iii) N(X) ⊂ int X, то всякий нуль f в X лежит
в N(X) ⊂ int X.

*Схема доказательства* (классика: Moore 1966; Krawczyk 1969; Alefeld–
Herzberger; Neumaier, Thm 5.1.8, комплексный случай). Существование:
рассмотрим k(x) = x − Y·f(x); по комплексной форме теоремы о среднем
(интегрирование f' по отрезку [c₀,x] ⊂ X — шар выпуклый)
k(x) = c₀ − Y·f(c₀) + (x−c₀) − Y·f'(ξ_x)(x−c₀) ∈ K(X) для всех x ∈ X;
K(X) ⊂ int X ⇒ по неподвижной точке Брауэра k имеет неподвижную точку
x* ∈ int X, а неподвижные точки k — в точности нули f (Y ≠ 0).
Единственность: если f(c₁)=f(c₂)=0, то 0 = f(c₁)−f(c₂) = (c₁−c₂)·∫f'(γ)dt,
интеграл лежит в выпуклой оболочке f'(X) ∌ 0, откуда c₁ = c₂.
Ньютоновская часть: для нуля x* ∈ X, 0 = f(x*) = f(c₀) + f'(ξ)(x*−c₀)
⇒ x* = c₀ − f(c₀)/f'(ξ) ∈ N(X).

**Теорема (главное утверждение пакета).** Для каждого из 23 боксов
X_k = B(c₀_k, r_k) из `mside_certificate.json` выполнены условия (i)–(iv).
Следовательно, в каждом X_k существует единственный нуль c*_k функции
c ↦ P_c^{2048}(0), и так как inf_{c∈X_k} |P_c^{2^j}(0)| > 0 при всех
j = 0..10, критическая орбита возвращается в 0 впервые ровно на итерации
2048 = 2^{m+1}: c*_k — суперстабильный параметр ТОЧНОГО периода 2^{m+1}.
(Множество времён возврата критической орбиты кратно минимальному;
2048 = 2^{11} делится только на d = 2^j, поэтому перебор j = 0..10 полон.)
23 корня лежат в 23 непересекающихся боксах (минимальное попарное расстояние
центров 1.02e-8, пара Z69/Z70, против 2r = 2e-27 — запас ~5·10^{18}), т.е.
это 23 различных параметра.

### 3.1. Почему распространение по квадрату доказывает утверждение о диске

Генератор вычисляет включения (D = f'(X), N, K, все period-checks) по
квадрату X = c₀ + [±r]² ⊇ B(c₀, r), а все PASS-проверки сравнивает с r;
guard «радиусы обеих компонент X ≥ r» гарантирует включение диска в
квадрат: B(c₀, r) ⊆ X. Тогда:

* |K−c₀|_ub < r влечёт K ⊂ B(c₀, r): для всякой точки k ∈ K выполнено
  |Re(k−c₀)| < r и |Im(k−c₀)| < r, т.е. K строго внутри открытого
  квадрата int X;
* интеграл среднего значения по отрезку [c₀, x] ⊂ X (квадрат выпуклый)
  лежит в X, поэтому D = f'(квадрат) годится для леммы: k(x) = x−Y·f(x)
  отображает каждое x ∈ X в K ⊂ X, и по Брауэру нуль существует (и лежит
  в K ⊂ B(c₀, r));
* единственность получается во всём квадрате X ⊇ B(c₀, r) (интеграл по
  отрезку [c₁,c₂] ⊂ X лежит в D ∌ 0);
* существование — нуль лежит в N(X), |N−c₀|_ub < r, т.е. внутри диска
  B(c₀, r).

Итого: утверждение теоремы для диска B(c₀, r) сохраняется дословно при
распространении включений по надмножеству-квадрату (фикс по
AUDIT_FINDING.md, п. 3).

## 6. Аудит (2026-08-14): дефект генератора и его устранение

Внешний аудит пакета (фикс-задание `AUDIT_FINDING.md`) нашёл дефект
`mside_certificate.py` первого прогона: строка `W = C(A("[+/- r]"), A(0))`
задавала НУЛЕВОЙ мнимый радиус бокса, поэтому X = c₀ + W покрывал лишь
горизонтальный ОТРЕЗОК [Re c₀ ± r] × {Im c₀} (радиус Im-компоненты ~1e-162
— только погрешность представления десятичной строки), а не заявленный диск
B(c₀, r). Следствие: f'(X) и все period-checkы сертификата от 16:24
действовали по отрезку, и теорема в заявленной форме (диск) первичным
кодовым путём доказана не была.

`mside_verify.py` при этом КОРРЕКТЕН: он всегда распространял честный диск
(кортеж (re, im, r)) и по заданию аудита не менялся; его подтверждение
(exit 0) фактически уже являлось звуковым подтверждением утверждения о
диске независимым путём.

Фикс генератора (AUDIT_FINDING.md, пп. 1–4): W = [±r] × [±r] — квадрат,
надмножество диска; r — наружная верхняя грань максимума радиусов обеих
компонент W (без опоры на `acb.rad()` для двухкомпонентного шара); все
PASS-проверки оставлены против r (обоснование корректности — §3.1);
добавлен guard «радиусы обеих компонент X ≥ r» до запуска орбит — защита
от регрессии этого же дефекта.

Почему численные значения почти не изменились: вклад радиуса бокса
r ~ 1e-27 в орбиты — размытие ~1e-21 относительно модулей середины
(~1e-4…1.4), поэтому все границы сдвинулись только в далёких хвостовых
знаках; таблица §4 совпадает с прежней во всех 4 значащих цифрах, все 23
корня сертифицировались на первом элементе лестницы (r = 1e-27, 512 бит).

После фикса: `mside_certificate.json` перегенерирован (23/23 pass);
`mside_verify.py` — exit 0; `run_tampers.py` — 10/10 порч пойманы, чистый
контроль exit 0 (`TAMPER_LOG.md` обновлён).

## 7. Ограничения (честные границы доказанного)

* Доказано существование/единственность и точный период 23 суперстабильных
  параметров в указанных боксах. НЕ доказано соответствие между нулями H и
  этими параметрами через u = A(c−c_F)δ^m — это численная калибровка
  (v2_work), её строгость — отдельная будущая задача.
* c_F, A, δ не сертифицируются и не используются в доказательстве
  (орбитальные проверки самодостаточны).
* Периоды взяты из данных results.json (все 2048); скрипты не хардкодят
  значения — при другом входе лестница/структура проверок перестроятся
  автоматически.

## 8. Как перезапустить

```
cd mside_superstable
python mside_certificate.py   # ~0.5 с, 23 корня, ProcessPool(max_workers=10)
python mside_verify.py        # ~0.5 с, независимый пересчёт всего
python run_tampers.py         # ~6 с, 10 порч + чистый контроль -> TAMPER_LOG.md
```

Жёсткая директива владельца: `max_workers=10, НЕ БОЛЬШЕ` (машина
используется параллельно) — соблюдена в обоих параллельных скриптах.
Выходные коды: генератор и верификатор возвращают 0 только при полном
проходе; `run_tampers.py` — 0 только если все порчи пойманы и чистый
контроль зелёный.

# Явная реализация соответствия «параметр ↔ неустойчивое многообразие» для классов универсальности удвоения периода

**Yevhen Borzenkov** · ORCID [0009-0002-7946-589X](https://orcid.org/0009-0002-7946-589X)
Препринт, версия 0.7.4 (заморожена 16.08.2026), не рецензирован. Публичное издание 15.11.2026.
English version — [README.md](README.md).

Статья-компаньон к [feigenbaum-h-zeros](https://github.com/ultrathinker/feigenbaum-h-zeros) (квадратичный класс d = 2).
Здесь тот же узор нулей универсальной функции H_d прослежен по классам |x|^d при d = 2, 4, 6: нули H_d кодируют
геометрию пространства параметров каждого класса, а не только квадратичного.

## Главные результаты

Строго (компьютерное доказательство, интервальный оператор Кравчика и интервальный Ньютон, python-flint / Arb):

- **357 сертифицированных боксов** сверхустойчивых параметров: 61 при d = 4 (период 1024), 287 при d = 6 (период 1024),
  9 поздних при d = 6 (периоды 2048, 4096, 8192); для каждого — существование, единственность и точный период.

Численно проверено (сертифицированное собственное значение коллокационной дискретизации; хвост N → ∞ оценён, но не сертифицирован):

- λ₂(4) = 0.2918384089835451…, λ₂(6) = 0.3710714676819301… (и λ₂(2) из соседнего расчёта «Мост»).

Аналитически: предложение о калибровочной башне — Φ_k точный собственный вектор DT со значением α^(−dk)
при dk ∈ 2ℤ (приложение A).

Не строго, и так и сказано: само соответствие «нуль ↔ параметр» (22/23 при d = 2, 61/62 при d = 4, 287/294 при d = 6),
полнота каталогов, спектральная сетка d ∈ [1.9, 7] с точкой смены d* = 2.3616 ± 0.0008, закон скорости
rate = min(δ, 1/|λ₂|) в наших данных. Сам закон известен (Mao–Hu 1987, Reick 1992, Briggs 1994); существование и
гиперболичность неподвижных точек при чётных d — Эпштейн, Любич, Авила–Любич, Burbanks–Osbaldestin–Thurlby.
Полный список ограничений — §7.4 статьи.

## Как воспроизвести

Python 3.13, `python-flint` 0.9.0, `mpmath` 1.3.0, `numpy`, `scipy`. Скрипты запускать из их папки
(`python -X utf8 <скрипт>`). Быстрые проверки: `python _tools/verify_manifest.py`, затем
`krawczyk4_verify.py`, `krawczyk6_verify.py`, `krawczyk6_late_verify.py` в своих папках `05-CODE/sec3_krawczyk_*` —
на этом издании (15.11.2026) все проходят.

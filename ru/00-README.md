# Явная реализация соответствия «параметр ↔ неустойчивое многообразие» для классов универсальности удвоения периода

Самодостаточный комплект материалов исследования: статья, два приложения, литература и репликационный пакет с кодом и данными под sha256-манифестом. Все определения, все числа, входящие в выводы, и все шаги доказательств содержатся внутри этих файлов. Внешние ссылки ведут либо в другое место комплекта, либо в опубликованную литературу.

Дополнительной доводки центра или формы среднего значения для F′ не требуется.

**Численно верифицировано (сертифицированное собственное значение коллокационной дискретизации; ошибка усечения N → ∞ оценена по лестнице, но формально не сертифицирована):**

- **λ₂(2) ± 1.82·10⁻³³ — численно верифицировано:** сертифицированное собственное значение коллокационной дискретизации N = 48 (смежный проект «Мост»).
- **λ₂(4), λ₂(6) — численно верифицировано:** сертифицированные собственные значения коллокационной дискретизации N = 40 (d = 4) и N = 48 (d = 6); чебышёвский базис, радиусы шаров ~10⁻⁴⁰; усечение N → ∞ оценено по лестнице (~10⁻²⁶ на последнем шаге). Три величины (λ₂(2), λ₂(4), λ₂(6)) имеют одинаковый статус «численно верифицировано» (§2.3, шкала статусов строгости).

**Предложение о калибровочной башне (Приложение A):** формальное тождество DT·Φ_k = α⁻ᵈᵏ·Φ_k на нечётной вещественной ветви при dk ∈ 2ℤ ∩ ℝ₊ (и поточечно на нечётной ветви при любом вещественном dk > 0). Тождество — формальное для неподвижной точки g_d; существование при чётных d — Epstein (1986), единственность и гиперболичность — Lyubich (1999) и Avila–Lyubich (2011); d = 2 — Lanford (1982); d = 4 — CAP-границы Burbanks–Osbaldestin–Thurlby (2021). Численная сверка тождества выполнена на коллокационном приближении g_d (невязка ≤ 2·10⁻²⁰ для целых чётных dk и ≤ 8·10⁻²⁴ для дробных/нечётных dk на нечётной вещественной ветви; A.5.1, A.5.2). Атрибуция классике: см. §A.6 приложения A.

**NOT RIGOROUS** — численно подтверждено, но не сертифицировано (по «Карте зависимостей» в конце `01-ARTICLE.md`):

- **d_u-слой (§3):** 22/23 (d = 2), 61/62 (d = 4), 287/294 + 296/296 (d = 6 при m = 9…12) — соответствие нулей H_d каталожным суперстабильным параметрам; статус — **NOT RIGOROUS (численное соответствие; сертифицированы только концы пар)**, согласовано с §3.2. Сам d_u-слой зависит от несертифицированных констант пересчёта (c_F, A, δ); сертифицированы сами боксы (см. выше).
- **Полнота каталогов:** не заявляется ни для одного из трёх классов (146 vs 62 при d = 4; 641 vs 342 при d = 6, см. §3.2, §3.3).
- **Решётка шага 1/16 — артефакт селекции сканера** (§3.3, §7.2): установлено для d = 4 и d = 6 одним протоколом (перескан несоизмеримой сеткой 1/24); показатели у узлов — шум отбора кандидатов среди локальных минимумов |H| на сетке; сами узлы не «почти-нули» H.
- **Продолжение ветви B⁺ в направление башенной моды Φ₁ вблизи d = 4 и d = 6** (ранее — «тень»): симметрично, cos собственных функций = 1 − O(10⁻⁸) при Δd ∈ [0.0005, 0.01], N = 48/64, два базиса (`05-CODE/sec2_tower_shadow_small_dd/`); косинус коэффициентов Φ₁ и B⁺ в мономиальном базисе — базисно-зависимая величина, не свидетельство асимметрии d = 4 / d = 6 (§2.5, Supplement §S1); NOT RIGOROUS.
- **Закон скорости сходимости rate = min(δ, 1/|λ₂|):** свидетельства в наших данных — NOT RIGOROUS (float/mpmath); как факт литературы — условно-строгий (Mao–Hu 1987; Reick 1992; Briggs 1994).
- **Спектральная сетка и кроссовер d\* = 2.3616 ± 0.0008** — NOT RIGOROUS; разрешение вопроса о смене знака λ₂ вблизи d = 2 — NOT RIGOROUS, но согласовано в трёх независимых испытаниях.
- **Статус принципа узора как такового** — формальной теоремы о H_d нет; набросок в §7.3.
- **Модель OOS «в пределах ×2»** (§7.3): d = 6 — подтверждена (~92 % vs baseline ~90.5 %); d = 4 — структурное превосходство над baseline не показано.

Полный перечень ограничений — §7.4 статьи.

## Открытые вопросы

Сводный список открытых вопросов по §7.4 и §8 статьи (в скобках — статус на сегодня):

1. **Полнота каталогов нулей H_d** (§7.4, п.1) — не заявляется ни для одного из трёх классов; количественные границы неполноты: перескан несоизмеримым шагом 1/24 находит 146 нулей уровня 8 против 62 (d = 4, ≈2.35×) и 641 против 342 (d = 6, ≈1.87×). Каталоги расширяемы, но полнота не достигнута.
2. **Поведение физической ветви B⁺(d) вблизи чётных d — аналитически** (§7.4, п.5) — численно ветвь продолжает башенную моду Φ₁ симметрично при d = 4 и d = 6 (cos собственных функций = 1 − O(10⁻⁸) при Δd ∈ [0.0005, 0.01]; NOT RIGOROUS, mpmath dps 40); Предложение §2.5 даёт только точное тождество в чётных точках, а не разложение ветви по Δd. Косинус коэффициентов Φ₁ и B⁺ в мономиальном базисе — базисно-зависимая величина, не свидетельство асимметрии d = 4 / d = 6.
3. **Хвост N → ∞ для λ₂(4), λ₂(6)** (§7.4, п.7) — сейчас только эвристическая оценка по лестнице N = 16 → 24 → 32 → 40 (d = 4) и до 48 (d = 6); ошибка усечения ~10⁻²⁶ на последнем шаге, но формальной сертификации предельного оператора нет.
4. **Формальная теорема о H_d** (§8) — соответствие «нуль ↔ параметр» остаётся эмпирическим NOT RIGOROUS слоем; набросок «пути к теореме» в §7.3 содержит четыре открытых подзадачи (интервальные якоря c_F, A, δ; простота нулей H; строгая версия остатка λ₂^m; формальный контроль u → 2u). В работе нет формального утверждения о нулевом множестве H_d или о его связи с параметрическим пространством в нелинейном случае.
5. **Механизм тяготения нулей H_d к решётке 1/16** (§7.4, п.8) — артефакт селекции сканера установлен для d = 4 и d = 6; почему «долина» малости |H| совпадает по масштабу с шагом сеток построения каталога — открытый вопрос.
6. **Строгая идентификация нашего коллокационного g_d с точной неподвижной точкой оператора T** (оценка ошибки усечения N → ∞) — не проводилась; численная сверка тождества (2) выполнена на коллокационном приближении (A.5.1, A.5.2). Существование неподвижной точки g_d при чётных d покрыто классическими теоремами Epstein (1986), Lyubich (1999) и Avila–Lyubich (2011).
7. **Литературная новизна принципа соответствия** (§7.1) — «вероятно ново» с оговорённым остаточным риском приоритета (kneading-теория/MSS-комбинаторика, журнальные источники 1980–1990-х — не сверены построчно).
8. **Закон min(δ, 1/|λ₂|) как формальная теорема** (§8) — современное подтверждение в данных NOT RIGOROUS; независимого от Briggs (1994) доказательства min-правила как теоремы в работе нет.
9. **d_u-слой и метрика специфичности** — неоднородна между классами (per-zero для d = 2, per-rival для d = 4, 6); прямое сравнение чисел 82339× и 1488× некорректно.
10. **Модель OOS «в пределах ×2»** (§7.4, п.6; §7.3) — для d = 4 при n = 61 структурное превосходство над baseline этим критерием не показано.
11. **Возможное продолжение на четвёртый класс универсальности или на классы с нечётным показателем максимума** (§8) — самостоятельная задача, работа её не предвосхищает.

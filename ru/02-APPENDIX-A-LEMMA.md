# Приложение A. Предложение о калибровочной башне для класса |x|^d: формулировка, доказательство, численная проверка

*Приложение к статье «Явная реализация соответствия «параметр ↔ неустойчивое многообразие» для классов универсальности удвоения периода». Алгебраическое тождество формально строгое при данной фиксированной точке g; численная часть — NOT RIGOROUS (mpmath float); подтверждение поточечного тождества на нечётной вещественной ветви [G]^{dk+1} при всех dk>0 и численная сверка с аналитической башней при dk∈2ℤ.*

---

## A.1 Постановка и оператор

**Класс объектов.** Пусть d > 1 — параметр класса универсальности Цвитановича–Фейгенбаума. Рассматриваем функции от x ∈ ℝ вида f(x) = F(|x|^d), где F — гладкая функция от t = |x|^d, с нормировкой F(0) = 1 (т.е. f(0) = 1). Функция чётная по x; в x-представлении — чётная функция от |x|^d. Это рабочее функциональное пространство: **вещественно-аналитические чётные функции от x класса C^ω** на [−1, 1] (что эквивалентно вещественно-аналитическим функциям от t ∈ [0, 1]).

**Функциональное уравнение и неподвижная точка.** Оператор удвоения Цвитановича в реализации проекта:

  T(f)(x) = −α_f · f(f(x/α_f)),   α_f = −1/f(1).

В t-представлении F(t) = G(t) — неподвижная точка, G(0) = 1, и

  G(t) = −α·G(W(t)),   τ = t/α^d,   U = G(τ),   W = |U|^d,

где α = α_G = −1/G(1) — константа Фейгенбаума данной степени d. Из определения:

  K(t) := G(t) − d·t·G′(t),    a₀ := G(1) = −1/α.

**Линеаризация.** На возмущениях Φ(t) с Φ(0) = 0 фреше-производная T в точке G имеет вид

  (DTΦ)(t) = −(Φ(1)/G(1))·K(t) − α·Φ(W(t)) − α·d·sign(U)·|U|^{d−1}·G′(W)·Φ(t/α^d).   (∗)

Это эквивалентно разбиению DT = gauge + J + S: первое слагаемое — калибровочный вклад вариации α_f; J(Φ) = −α·Φ(W) — внутренняя композиция; S(Φ) = m(t)·Φ(τ) с m(t) = α^d·G′(t)/G′(τ) — перенос аргумента. Формула (∗) проверена конечно-разностной сверкой с истинным нелинейным оператором T в пакете `appA_lemma_verify_B/`.

**Переход к x-представлению.** Если положить t = |x|^d, W = |U|^d = |G(τ)|^d, τ = t/α^d = |x|^d/α^d = |x/α|^d, то t/α^d = |x/α|^d, и Φ(W(t)) = Φ(|G(|x/α|^d)|^d). В записи через g(x) = G(|x|^d) и возмущения φ(x) := Φ(|x|^d) получаем оператор удвоения в x-представлении; это соглашение используется в A.3 для короткого вывода.

## A.2 Предложение (калибровочная башня для класса |x|^d)

**Предложение (поточечное тождество + критерий аналитичности).**
Пусть d > 1, α > 0, g вещественна на [−1, 1], k ≥ 1, и пусть w_k(x) := x·|x|^{dk} − x. Определим

  **Φ_k(t) := G(t)^{dk+1} − d·t^{k+1}·G′(t) − K(t)**,     Φ_k(0) = 0.        (1)

Тогда при **любом** вещественном dk > 0 для Φ_k в форме (1), понимаемом на нечётной вещественной ветви [G]^{dk+1} := sign(G)·|G|^{dk+1} при dk ∉ 2ℤ (см. A.3.2 об условиях дифференцируемости и однозначности выбора ветви), выполнено **поточечное тождество**

  **DTΦ_k(t) = α^{−dk}·Φ_k(t)**    для всех t ∈ [0, 1].                    (2)

Функция Φ_k в виде (1) **принадлежит вещественно-аналитическому классу** C^ω([0,1]) (и, эквивалентно, аналитическому классу чётных функций от x) при dk ∈ 2ℤ (чётное целое; это требование чётности показателя степени в G(t)^{dk+1}, чтобы избежать излома в нулях G и в x = 0); обратное направление (Φ_k ∈ C^ω ⇒ dk ∈ 2ℤ) установлено при простых нулях G на (0, 1). При dk ∈ 2ℤ Φ_k — аналитический собственный вектор DT с собственным значением α^{−dk}. На обычной целой ветви G^{dk+1} при dk ∉ 2ℤ тождество (2) **не** выполняется (численная сверка: d=3, k=1, dk=3, обычная ветвь — rel ≈ 0.465; A.5); на нечётной ветви [G]^{dk+1} — выполняется (rel ≈ 5.4·10⁻³⁰ для того же (d, k); A.5.2), но Φ_k ∉ C^ω.

**Следствие 1 (башня при чётных d).** Если d — целое чётное, то для всех k = 1, 2, 3, … произведение dk автоматически чётно ⇒ **вся последовательность {α^{−dk}}_{k ≥ 1} — собственные значения DT** в аналитическом классе.

**Следствие 2 (прореженная башня при нечётных целых d).** Если d — целое нечётное, то dk чётно ⇔ k чётно. Аналитические собственные векторы Φ_k в классе C^ω существуют только при чётных k; первый уровень — k = 2 с собственным значением α^{−2d}.

**Следствие 3 (K → α^d·K).** Тривиальная координатная мода K(t) = G(t) − d·t·G′(t) — собственный вектор расширенного оператора (без условия Φ(0) = 0) с собственным значением α^d. Двухстрочная выкладка: (1) сравнение коэффициентов при |x|^d в g(x) = −α·g(g(x/α)) ⇒ g′(1) = −α^{d−1} (A.4.4, численная сверка до машинной dps 40 в A.5.4); (2) тогда DT_полн(K)/K = α^d (численная сверка: α² = 6.264547831… для d = 2; α_6^6 = 9.997677674… для d = 6; A.5.4). Это следствие — прямое вычисление из структуры неподвижной точки; не требует сопряжения χ_ε.

**Следствие 4 (рациональные и иррациональные d).** При d рациональном p/q (несократимая дробь) аналитические члены башни появляются при dk = p·k/q ∈ 2ℤ, т.е. при k, кратных 2q (если p нечётно) или q (если p чётно). Минимальное k₀ ∈ ℕ с p·k₀/q ∈ 2ℤ задаёт первый уровень. При d иррациональном никакое dk не целое ⇒ Φ_k при всех k не аналитичен ⇒ аналитических членов башни нет.

## A.3 Доказательство

_Навигация._ §A.3.1–A.3.2 используют конструкцию сопряжения χ_ε и работают при dk ∈ 2ℤ (дают «Следствие 1/2» о башне). §A.3.3 — самостоятельное общее доказательство для всех dk > 0 на нечётной вещественной ветви; не зависит от A.3.1–A.3.2 логически. Численная сверка A.5.2 (4 строки, дробные/нечётные dk) относится именно к A.3.3.

### A.3.1. Сопряжение χ_ε = id + ε·w (≤ 1 стр.)

Пусть χ_ε = id + ε·w, w(x) = x^n − x, n = dk + 1. Условия w(0) = 0 и w(1) = 0 сохраняют нормировку f(0) = 1. Семейство f_ε = χ_ε ∘ g ∘ χ_ε⁻¹ даёт φ := d/dε f_ε|_0 = w ∘ g − g′·w. В t-представлении с t = |x|^d, g(x) = G(t) получаем (1).

### A.3.2. Генератор w̃ для T (≤ 1 стр.)

Для f_ε в классе T ∘ χ_ε = χ̃_ε ∘ T, где χ̃_ε = id + ε·w̃ с w̃(x) = w(a·x)/a − w(a)·x/a, a := f(1). При a₀ = G(1) = −1/α и dk ∈ 2ℤ имеем a₀^{dk} = (−1/α)^{dk} = α^{−dk}, откуда w̃(x) = a₀^{dk}·w(x) = α^{−dk}·w(x). T(f_ε) ≈ f_{ε·α^{−dk}} ⇒ DT отображает Φ_k в себя с весом α^{−dk}. ∎

*Условия применимости.* (i) g вещественна класса C^1 на [−1, 1]; (ii) при dk∉2ℤ выбирается непрерывная вещественная ветвь G^{dk+1} := sign(G)·|G|^{dk+1} — определена однозначно всюду, где G ≠ 0; в нулях G ветвь [G]^{dk+1} имеет излом ровно в тех точках, которые и образуют аналитическое препятствие (A.2). (iii) Комплексное возведение в степень (a₀)^{dk} используется лишь в случае dk ∈ 2ℤ: при dk = 2m имеем a₀^{dk} = (G(1))^{2m} = (G(1)^2)^m ≥ 0, и выбора ветви корня не требуется.

### A.3.3. Доказательство в x-представлении (≤ 1 стр.)

Используем обозначение φ(x) := Φ_k(t = |x|^d) — та же функция-собственный вектор в x-представлении, эквивалент (∗) через цепное правило t = |x|^d. В x-представлении:

  DTφ(x) = α·φ(1)·K(x) − α·φ(g(x/α)) − α·g′(g(x/α))·φ(x/α).     (∗∗)

Подстановка φ = w ∘ g − g′·w с w(x) = x·|x|^{dk} − x. Калибровочный член: φ(1) = w(g(1)) = w(−1/α) = −α^{−(dk+1)} + α^{−1}, итого α·φ(1) = 1 − α^{−dk}, так что калибровочный член = (1 − α^{−dk})·K(x). В средних двух слагаемых члены ±α·g′(g(x/α))·w(g(x/α)) взаимно сокращаются; оставшиеся −α·w(g(g(x/α))) и +α·g′(g(x/α))·g′(x/α)·w(x/α) после разложения w на −g(x)/α (по уравнению неподвижной точки g(g(x/α)) = −g(x)/α) дают α^{−dk}·φ(x) − (1 − α^{−dk})·K(x). Итого:

  DTφ(x) = (1 − α^{−dk})·K(x) + [α^{−dk}·φ(x) − (1 − α^{−dk})·K(x)] = α^{−dk}·φ(x).   (2)

K-слагаемые сокращаются между калибровочным членом и остатком одной строкой.

**Связующее звено (g-цепное правило).** Дифференцируя тождество неподвижной точки g(g(x/α)) = −g(x)/α по x (g класса C^1 см. A.3.2), получаем

  g′(g(x/α))·g′(x/α)·(1/α) = −g′(x)/α,   ⇒   g′(g(x/α))·g′(x/α) = −g′(x).

Это равенство подставляется в (∗∗) вместе с дифференцированием g(g(x/α)) и лежит в основе группировки «−α·w(g(g(x/α))) + α·g′(g(x/α))·g′(x/α)·w(x/α) = α^{−dk}·φ(x) − (1−α^{−dk})·K(x)». ∎

*Замечание.* Поточечная численная проверка на сетке t ∈ (0, 1] для d ∈ {2, 4, 6} при dk ∈ 2ℤ даёт остаток ≤ 10⁻²⁵ (N = 48, mpmath dps 40; A.5). Численная сверка при повышенных N и оценка усечения — A.5.1.

## A.6 Атрибуция, статус строгости и открытые вопросы

### A.6.1. Атрибуция классике

Собственные значения замен координат x → x + εx^n со значением α^{1−n} — классический факт: Feigenbaum (1979), Collet–Eckmann–Lanford (1980), Cvitanović «Universality in Chaos» (1989), Christiansen–Cvitanović–Rugh (1990, *J. Phys. A* 23, L713), Briggs (1994, arXiv:chao-dyn/9407019) явно говорит о «gauge». Условие нечётности n — фольклор теории удвоения. Обобщение на класс |x|^d — следствие конструкции χ_ε = id + ε·(x|x|^{dk} − x), выполненное в данной работе.

**Что в данной работе нового:** (1) явная t-форма Φ_k (1) для прямой численной проверки; (2) критерий аналитичности Φ_k ∈ C^ω ⇔ dk ∈ 2ℤ (единый критерий аналитичности и попадания в спектр DT); (3) численная сверка башни при d = 2, 4, 6, 8 (A.4.1) и при нечётных d (A.4.2).

### A.6.2. Статус строгости

**Алгебраическое тождество** (2) DTΦ_k = α^{−dk}·Φ_k на нечётной вещественной ветви [G]^{dk+1} — **строгое** при данной фиксированной точке G: достаточно G вещественна и dk > 0, чтобы при подстановке Φ_k в (∗) получилось сокращение. Формально доказано в A.3 для всех d > 1 при dk > 0 на ветви [G]^{dk+1}; на аналитическом классе — при dk ∈ 2ℤ.

**Строгость в целом** (условно-СТРОГО) = строгость существования неподвижной точки g_d оператора T(f) = −α_f·f(f(x/α_f)). Два подшага: (a) **алгебраическое тождество** (2) — формально строгое при данной фиксированной точке G; (b) **существование и единственность g_d** при чётных d — из литературы. Тождество (2) — формальное тождество для этой неподвижной точки; его численная сверка выполнена на коллокационном приближении g_d (таблицы A.5.1/A.5.2; невязка ≤ 2·10⁻²⁰ для целых чётных dk и ≤ 8·10⁻²⁴ для дробных/нечётных dk на нечётной вещественной ветви, как было). В литературе: существование при чётных d ≥ 4 — Epstein (1986, *Comm. Math. Phys.* 106, 395–426; аналитическое доказательство существования функционального уравнения в классе чётных функций общей степени в критической точке); единственность и гиперболичность неподвижной точки для произвольной чётной целой степени — Lyubich (1999, *Ann. of Math.* 149, 319–420) и Avila–Lyubich (2011, *Publ. Math. IHÉS* 114, 171–223; ренормализационная подкова, экспоненциальное сжатие вдоль гибридных классов); d = 2 — Lanford (1982, *Bull. Amer. Math. Soc.* 6, 427; компьютерно-ассистированное доказательство); d = 4 — Burbanks–Osbaldestin–Thurlby (2021, *J. Math. Phys.* 62, 112701; CAP-границы на неподвижную точку, α, δ и собственные функции при степени 4, более 320 значащих цифр). Для d = 8 численные «сертификаты» (`sec2_tower_depth_A/`, `sec2_tower_depth_B/`): плотный остаток 6.96·10⁻³⁶ при N = 48/56; совпадение с независимым решением до 17 значащих цифр — численная, не интервальная верификация.

**Итог без завышения**: тождество (2) доказано поточечно на нечётной ветви при dk > 0; справедливость для конкретных численных g_d подтверждена с точностью до точности входных данных коллокации; существование неподвижной точки g_d при чётных d покрыто классическими теоремами Epstein (1986), Lyubich (1999) и Avila–Lyubich (2011).

### A.6.3. Открытые вопросы

1. **Поведение физической ветви B⁺(d) вблизи чётных d — аналитически.** Численно ветвь продолжает башенную моду Φ₁ симметрично при d = 4 и d = 6 (A.4.2; cos собственных функций = 1 − O(10⁻⁸) при Δd ∈ [0.0005, 0.01]); Предложение A.2 даёт лишь тождество в самих чётных точках и ничего не утверждает о ветви при Δd ≠ 0. Аналитическое описание (например, разложение B⁺(d₀ + Δd) по Δd) не получено. Косинус коэффициентов Φ₁ и B⁺ в мономиальном базисе — базисно-зависимая величина и не свидетельствует об асимметрии между d = 4 и d = 6; в чебышёвском базисе cos = 1 − O(10⁻⁸) (A.4.2).

2. **Строгая идентификация нашего коллокационного g_d с точной неподвижной точки оператора T** (оценка ошибки усечения N → ∞ между коллокационным приближением и предельным объектом) — не проводилась; численная сверка тождества (2) выполнена на коллокационном приближении (A.5.1, A.5.2).

3. **d = 2.05, k = 40** — первый член «прореженной» башни (α⁻⁸²); численная проверка невозможна при N = 48 (G(t)⁸³ теряет точность). Требует N ≥ 100 или специальной конструкции.

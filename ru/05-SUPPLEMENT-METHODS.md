# Supplement — Методологические детали

Дополнение к статье «Явная реализация соответствия "параметр ↔ неустойчивое многообразие" для классов универсальности удвоения периода»; нумерация разделов S1…S9; в каждом разделе указано, к какому разделу основного текста он относится.

## S1. Артефактные ловушки численного маршрута (= M1; относится к §5)

Пять систематических ошибок конвейера, зафиксированных как предостережение для воспроизведения: (1) исходный каталог d = 2 хранит позицию каскада на уровне m = 7 точно, а не экстраполированный предел — лечится методом Ричардсона перед использованием как якоря; (2) циркулярность хвоста каскада (§5.4) — опорная константа a_F, построенная Ричардсоном из верхних уровней того же каскада, делает эти уровни тождественно циркулярными для фита, использующего ту же константу (сигнатура — совпадение отношения поправок с δ до 11 значащих цифр); (3) ошибка ε опорной константы инжектирует растущий, а не убывающий паразитный член A·ε·δ^m (§5.4; для d = 4 ε ≈ 8.6×10⁻²² при заявленных 4×10⁻²³ объяснила выброс отношения); (4) критерий малости шага Ньютона лжёт на хаотических орбитах (шаг может стать исчезающе мал при большом фактическом остатке |x_P|) — обязательна прямая проверка остатка орбиты; (5) косинус между собственными векторами дискретизованного оператора нельзя брать по векторам коэффициентов в мономиальном базисе {t^j} при N ≳ 48: базис плохо обусловлен, и коэффициентный косинус двух почти совпадающих функций может быть 0.05–0.7 (источник кажущейся «асимметрии d = 4 / d = 6» — базисно-зависимый артефакт метрики, §2.5) — сравнивать нужно значения функций на общей сетке или коэффициенты в чебышёвском базисе.

## S2. Спектральная охота (= M2; относится к §2.3, §2.4)

Дефлированная степенная итерация (вычленить ведущее собственное значение, вычесть вклад, повторить) ломается для d = 2 после 2–3 уровней и для d = 6 — с самого начала (сильная неренормальность матрицы линеаризации). Рабочий маршрут: полная диагонализация (mpmath.eig) либо лестница по N со сдвинутой обратной итерацией и контролем функциональным остатком на плотной сетке. Этим маршрутом исправлен знак λ₃(4) (§2.3) и подтверждена простота α^(−2) при d = 2 (§2.4).

## S3. Медленные ряды и бутстрап на плоских картах (= M3 + M4; относится к §6.3)

Хвост разложения H_d при N = 48 — порядка 10⁻¹⁷ для d = 4, но лишь 3×10⁻⁶ для d = 6; окно отсечения ряда калибруется на фактический хвост класса, а не наследуется. При больших d (≈ d ≥ 13) метод Ньютона от приближения предыдущего уровня каскада на плоских картах систематически не сходится; решение — сканирование плюс бисекция по знаку x_{2^k}(a), не применённое в одном из прогонов свипа (пропуск узла d = 8 в Т6.1, §6.3).

## S4. Порчи (tamper testing) (= M5; относится к §4)

Для обоих сертификационных прогонов Кравчика и для «Моста»/«Моста-2» применена батарея умышленных искажений входа и готовых сертификатов (пересборка испорченного входа генератором; прямая подделка полей сертификатного файла), внутренне согласованных, не выявляемых проверкой синтаксиса: 14/14 (d = 4), 16/16 (d = 6, включая типы для двухслойной структуры сидов), 8/8 (первая попытка «Моста»), 24/24 (8 типов × 3 точки, «Мост-2»); позитивные контроли чисты.

## S5. Форензика решётки шага 1/16 (d = 4 и d = 6; относится к §3.3, §7.2)

**Определение «у узла» (дословно, B.6.1).** frac16(x) = min((16x) mod 1, 1 − (16x) mod 1); точка «у узла» ⇔ frac16 < 1/16, т.е. |x − k/16| < 1/256 для некоторого целого k (по каждой координате отдельно); нулевая модель — равномерная: 12.5 % на координату, 1.5625 % joint.

Каталожные позиции девяти отказников лежат необычно близко к узлам решётки 1/16 в u-плоскости; проверка на всём каталоге d = 4, d = 6 показала, что близость к узлам — свойство каталогов в целом (по полным каталогам: per-coordinate 36.1–52.9 %, 2D joint 22.9–39.2 % против фона 1.56 %, p ≪ 10⁻¹⁵; в подмножестве ORIG-ONLY — нулей, потерянных пересканом, — заметно выше, до 69.0 % joint). Решающий тест — перескан несоизмеримым шагом 1/24 со случайным сдвигом (тот же конвейер, без спаривания уровней), одинаковый протокол для обоих классов.

*d = 4:* |orig| = 62, |new| = 146 (нулей уровня 8), |orig ∩ new| = 31 (= BOTH); ORIG-ONLY = 62 − 31 = 31 (потеряны пересканом), NEW-ONLY = 146 − 31 = 115 (найдены только пересканом). Доля у узлов (joint): ORIG-ONLY — 41.9 % (p = 5·10⁻¹⁶, максимум); BOTH — 6.5 % (p = 0.084, незначимо); NEW-ONLY — 0.0 %. Контроль «сдвинутая сетка 1/16» (74 нуля): к исходным узлам не льнут (joint 2.7 %, p = 0.32), к своим сдвинутым — сильно (31.1 %, p = 1·10⁻²³). Механизм: все 31 ORIG-ONLY потеряны на стадии отбора кандидатов (28/31 — узел не локальный минимум |H|, 0.2–3.7, не «долина»; 3/31 — невалиден по domain_check); Ньютон из валидного кандидата всегда сходится к нулю.

*d = 6:* 641 нуль уровня 8 против 342 оригинальных; матчинг BOTH = 155, ORIG-ONLY = 187, NEW-ONLY = 486 (`r1b_match.py` → `r1b_match.json`, REPORT-R1-LATTICE-RESCAN.md, §«0. Матчинг»); точное правило сопоставления пар BOTH между уровнем 8 (перескан) и каталогом уровня 9 в README/REPORT этого перескана не документировано текстом (указан только скрипт и результирующие счётчики). Доля у узлов (joint16): ORIG — 39.2 % (p = 4.5·10⁻¹⁴⁶); ORIG-ONLY — 69.0 % (Re 78.1 %, Im 80.2 %; p = 5.0·10⁻¹⁸⁵, максимум); BOTH — 3.2 % (p = 0.097, на грани значимости); NEW-ONLY — 0.0 % (нулевая модель 1.56 %). Причины потери всех 187 ORIG-ONLY (полный набор, не выборка): 86.1 % — узел не локальный минимум |H|, 12.8 % — невалиден по domain_check, 1.1 % — Ньютон сошёлся к другому нулю; тот же механизм отбора кандидатов, что при d = 4. Партнёр уровня m = 7 — бинарный разделитель: 100 % у BOTH/ORIG-ONLY, 0/60 в выборке NEW-ONLY. Подлинность (независимая проверка |H₈| < 10⁻¹⁵): 100 % во всех выборках (60 ORIG-ONLY, 60 NEW-ONLY, все 155 BOTH) — включая новые нули, они настоящие корни H₆, не мусор оптимизации; тест Ньютон-возврата из возмущения 1e-3 для d = 6 малоинформативен (проходит лишь 20–28 % даже у дважды подтверждённых BOTH — узкие бассейны притяжения степени 6, не признак подделки). Девять «поздних» нулей — предельный случай: максимальная «решёточность» в каталоге (100 % у узла q = 16), но пересканом не восстановлен ни один (0/9) — множество, отвергнутое стандартным конвейером и найденное лишь отдельным методом (интервальный Кравчик на m = 10–12, §4.3), пересканом не воспроизводится.

**Вывод для обоих классов: артефакт сеточной селекции**, установленный одним и тем же протоколом (доказано для d = 4 и d = 6). «Долина» малости |H| у многих нулей уже шага сетки, поэтому нуль попадает в каталог тогда и только тогда, когда узел сетки случайно оказался в его долине, — это и есть наблюдавшаяся «решётка».

Побочно: новые нули в обоих классах подтверждены как подлинные (|H₈| < 10⁻¹⁵ независимо; числа неполноты каталогов — §3.2) — статистики плотности/специфичности посчитаны на неполной выборке (§3.4, §7.4).

Для класса d = 2 решётка присутствует, но слабее: per-coordinate ≈ 30.2 % / 27.4 %, joint ≈ 12.9 % (441, с сопряжёнными); независимый пересчёт по 222 без сопряжённых — **13.51 %** (30/222; Приложение B.6.1, строка `unique222`; ранее ≈24 % не воспроизводятся). Контрольный подкаталог known23 (23 сертифицированных нуля, входящих в соответствие §3.2) решётку НЕ показывает: joint 1/23 (p = 0.30) — независимое подтверждение картины артефакта отбора: курируемый каталог, не построенный тем же грубым сканом, решётки не проявляет. Механизм тот же для всех трёх классов: близость к узлам сетки построения, не орбитальная комбинаторика.

## S6. Слой 2 — S078 и S090: хрупкость и перепроверка pow/mul (относится к §4.3)

Формат хранения сидов d = 6 (мнимая часть — float64, не точная строка) для большинства параметров несущественен (невязка ≤ 2.0×10⁻¹²), но для S078, S090 — точек с экстремальной |F′(a*)| ≈ 8.1×10¹⁴ и 1.1×10¹⁸ (самые плохо обусловленные в каталоге) — недостаточен: бокс вокруг хранимого сида не сертифицируется уже при радиусе 10⁻²⁵ (S078) / 10⁻²⁹ (S090) — оценка ДО перепроверки; сама перепроверка REPORT-R2-S090 стартовала с других, более узких радиусов 1e-30/1e-31 (следующий этап сужения, числа не противоречат друг другу). Решение: детерминированное уточнение — восемь итераций Ньютона при dps = 120, усечение центра до 60 значащих цифр; тождественность с корнем слепого прогона зафиксирована пином расстояния |c_уточнённый − сид|_верх = 1.74×10⁻²⁴ (S078) / 1.85×10⁻²⁴ (S090), оба < 5×10⁻²⁴ (ближайший чужой бокс — 2.6×10⁻¹⁰).

Независимая перепроверка (REPORT-R2-S090) обнаружила хрупкость исходного радиуса слоя 2 (r = 10⁻³¹ для S090) к порядку вычисления шестой степени: в авторском порядке (x⁶ = x**6) шар F′(X) не содержит 0 (относительная ширина |F′(X)| ≈ 6.8 %), но в математически эквивалентном порядке x⁶ = x⁵·x — уже содержит, и сертификат в этом порядке не проходит. Уменьшение радиуса до r = 10⁻³⁴ (prec = 512) снимает хрупкость: ширина шара |F′(X)| = 1.36×10⁻³ (mul) / 6.45×10⁻⁵ (pow) для S090, ≤ 1.14×10⁻⁷ для S078, в обоих порядках и на prec 256/512/1024. Финальные радиусы слоя 2 в приложении B: 1×10⁻³⁴ для S078 и S090. **Охват pow/mul-кросс-чека:** систематически прогнан на пяти боксах — S078, S090 (слой 2) и трёх контролях слоя 1 (S001, S172 — худшая изоляция, S180 — максимальный допустимый κ), не на всех 287; для остальных 282 боксов независимый второй кодовый путь (Т4.1-б) подтверждает результат только в одном (авторском) порядке возведения в степень.

## S7. «Мост-2» — подробный walk-through (относится к §4.4)

**λ₂(2).** Сертифицирована собственная пара N = 48-коллокации; редукция к предельному оператору (в духе Lanford / Eckmann–Wittwer) требует гипотез, которые здесь не проверяются. Итог: λ₂(2) = −0.1236527125526870243353936525855 ± 1.82×10⁻³³ (дискретизация N = 48) — статус **численно верифицировано** (§2.3), не «СТРОГО» для предельного оператора; полной сертификации оператора нет.

**λ₂(4), λ₂(6) — «Мост-2» (чебышёвский базис).** Первая попытка (мономиальный базис) дала строгие сертификаты для N = 16, 24, но с разрывом 18–30 порядков между сертифицированным центром и float-якорем Т2.1 — следствие роста обусловленности якобиана ~1000× на каждые +4 к N (сильная ненормальность оператора в мономиальном базисе). Перенос на чебышёвский базис (G(t) = Σ b_k T_k(2t−1), коллокация Гаусса–Чебышёва, тот же цепной Кравчик, стадии K1/K2) снижает рост обусловленности до полиномиального (~7·10⁵ при N = 16 до ~1.5·10⁸ при N = 48); K(X) ⊂ int(X) проходит на всей лестнице N = 16, 24, 32, 40 (d = 4) и до 48 (d = 6), радиусы шара λ₂ ~10⁻⁴⁰…10⁻⁴¹.

Сертифицированные центры: λ₂(4) = 0.291838408983545104530996961… (N = 40), λ₂(6) = 0.371071467681930132470983381… (N = 48). Ошибка усечения по лестнице убывает ускоренно: d = 4 — 4.2·10⁻¹² → 2.5·10⁻¹⁸ → 3.5·10⁻²⁶ (16→24→32→40); d = 6 — 2.1·10⁻⁸ → 3.0·10⁻¹⁴ → 3.8·10⁻²⁰ → 2.0·10⁻²⁶ (16→…→48). Оба float-якоря Т2.1 воспроизводятся сертифицированными центрами во всех 20 значащих цифрах.

**Три величины при N = 48 (d = 6), явно разведённые.** `trunc_vs_prev = 1.972×10⁻²⁶` — |λ₂^{(48)} − λ₂^{(40)}|, ошибка усечения лестницы Мост-2. `anchor_diff = 9.834×10⁻²²` — |λ₂(N) − anchor_λ₂|, расстояние до пилотного якоря; стагнация с N = 40 означает, что это точность самого якоря, а не сертификата. Отдельная несертифицированная проверка: независимое mpmath-Ньютоново продолжение до N = 44 воспроизводит якорь с точностью 1.88×10⁻²⁶ (d = 6) и 9.97×10⁻²² (d = 4) — третий, независимый путь.

**Статус (§2.3):** **численно верифицировано** — сертификат доказывает существование и единственность собственного значения системы коллокации указанного N в шаре, а не предельного оператора; строгая оценка хвоста N → ∞ остаётся за пределами работы. Батарея порч «Мост-2» — 24/24 (Supplement §S4); второй кодовый путь (dps 90) подтверждает невязки ~10⁻⁶⁹ и совпадение λ₂ до 64–65 цифр.

## S8. OOS / LOOCV-процедуры (относится к §7.3)

Модель невязки соответствия — двухчленная: e(m) ~ −(C·δ^(−m) + D·λ₂^m); наблюдаемое поведение — что доминирует медленный из двух членов.

- **Прямая детекция λ₂-моды под δ-слоем на d = 2 (наблюдение, требующее независимого воспроизведения).** После вычитания δ-слоя остаток знакопеременен (обязателен, поскольку λ₂(2) < 0): 5 знакочередований из 6 возможных, с отношением последовательных остатков 7.88–7.89 против предсказанного 1/|λ₂(2)| = 8.087. λ₂-мода под δ-слоем на d = 2 — NOT RIGOROUS (см. Карту зависимостей): конкретные уровни m, на которых зафиксировано это наблюдение, не переподтверждены отдельным воспроизведением с явной фиксацией m. Перекрёстная проверка leave-one-out показывает улучшение двухчленной модели относительно одночленной в 58 раз (калибровочные данные) и в 300–530 раз (данные о вещественных нулях H).
- **Слепое подтверждение на d = 6.** Расчёт класса d = 6 выполнен по замороженной процедуре, выбирающей наилучший показатель скорости сходимости из восьми кандидатов, не осведомлённой о законе min(δ, 1/|λ₂|) на момент работы. Протокол сам выбрал 1/λ₂(6) как наилучшее совпадение (среднее геометрическое отклонение −0.2 %, ближайший конкурент — +8.7 %).
- **Интерференция d = 6 объяснена.** Разброс наблюдаемых отношений d = 6 (0.6…7.5 в зависимости от диапазона m и пары параметров) — следствие почти вырожденной пары λ₂ = +0.371, λ₃ = −0.342 противоположных знаков (|λ₃/λ₂| = 0.922): их вклады интерферируют знакопеременно на низких m, прежде чем более медленный λ₂-слой не выйдет на первый план. У d = 4 пара λ₂ = +0.292, λ₃ = −0.256 тоже противоположных знаков, но менее вырождена (|λ₃/λ₂| = 0.876), и после коррекции опорной константы (§5.4) отношения там гладкие; полного количественного объяснения различия в силе интерференции между d = 4 и d = 6 работа не даёт. **Для d = 6 аналогичная ε-диагностика опорной константы a_F не проводилась**: медианы 2.556/2.830 в Т5.2 приведены без коррекции — статус явно отличается от d = 4, где коррекция сделана и задокументирована (Т5.3).

Замечание о циркулярности диапазона m: первоисточник указывает валидный диапазон m = 7…13 для отношения §5; m = 14…17 несёт артефакт рекурсии Ричардсона (a_F построена из тех же уровней) и в фит не включается (§5.4). Число 3.585 — не медиана по 13 нулям, как формулировалось ранее, а конкретное отношение ratio δ_{m+1}/δ_m при m = 12; независимая переимплементация даёт близкие пилотные значения (2.40, 4.91; среднее геометрическое 3.0150, 4.4337) на других парах уровней — оба ряда согласуются с одним и тем же λ₂-слоем в пределах ожидаемого разброса по m.

Расхождение между заявленной изначально точностью опорной константы a_F(4) (4·10⁻²³) и фактической диагностической ε-коррекцией (≈8.6·10⁻²²) — около 20 раз — источником этой работы не объяснено. Практическое следствие: **после ε-коррекции закон не даёт точечного предсказания для d = 4; вилка 3.36–3.46 — следствие неопределённости самого способа коррекции константы, а не внутренняя ошибка закона min(δ, 1/|λ₂|)**, который здесь верифицируется лишь на уровне порядка и знака отношения.

**Внешняя оценка δ₄.** Burbanks, Osbaldestin, Thurlby (2021) дают интервал δ₄ ∈ [7.28468621706, 7.28468621709] (условно-СТРОГО якорь); a_F(4) отдельной внешней сертификации не имеет.

Механическая интерпретация двухчленной модели (не доказанный в этой работе кандидат в теорему, §7.3): член C·δ^(−m) — генерическая поправка второго порядка сходимости вдоль неустойчивого направления, не требующая специфического субведущего спектра; член D·λ₂^m — прямой вклад субведущей существенной моды линеаризации. Кроссовер между классами: у d = 2 δ-член медленнее (8.087 > 4.669, доминирует), у d = 4, 6 — наоборот (7.285 > 3.4266; 9.296 > 2.6949) — отсюда запись rate = min(δ, 1/|λ₂|). При d = 2, 4 в фитах λ₂ входит тем значением, что численно верифицировано на дискретизации (d = 4) или для истинного оператора (d = 2); при d = 6 использованы операторные NOT RIGOROUS данные §6, а сертификат для N = 48 — независимая оценка того же значения для контроля.

## S9. Операторная сетка — детали (относится к §6.2)

Специальная операторная сетка из 45 точек по d ∈ [1.9, 7] (двойное усечение N = 40/48, контроль N = 56, функциональные остатки ≤ 10⁻²⁷) даёт следующую картину. **Гладкого нуля λ₂(d) нет:** обе субведущие ветви B⁺, B⁻ знакопостоянны на всём [1.9, 7], нигде не пересекаются. Смена знака классического λ₂ — скачок ровно в d = 2 (§2.4): при любом дробном d рядом с 2 существенны обе ветви и λ₂(d) = B⁺(d) > 0 (например, +0.15865 при d = 1.99, +0.15973 при d = 2.001), а отклонение B⁺ от калибровочного значения α^(−d) убывает линейно по (d − 2) с обеих сторон (наклон ≈ 0.114 на единицу d) — ветвь B⁺ гладкая и проходит СКВОЗЬ калибровочное значение, совпадая с ним точно (до 1.6×10⁻³⁰) ровно в d = 2.

**Кроссовер d*.** Точка, где закон меняет доминирующий член, определена условием δ(d)·λ₂(d) = 1 на ветви B⁺: бисекция даёт **d* = 2.3616 ± 0.0008** (δ = 5.2155, λ₂ = 0.19175 в этой точке). Оговорка о точности: ±0.0008 — точность отыскания корня на сетке §6, обе составляющие NOT RIGOROUS; кроссовер как предсказание закона независимо проверен только динамикой при d = 2.75 и 3.0 (ниже), не в самой точке d*.

**Динамическое подтверждение.** Прямое численное продолжение каскада (без вычисления спектра, непосредственным измерением скорости убывания поправок вдоль орбиты) до m = 16 в точках d = 2.75 и d = 3.0: скорость убывания монотонна (без знакочередований в надёжном окне m) со значениями 4.09–4.40 (d = 2.75, R² = 0.97–0.99) и 4.14–4.49 (d = 3.0), что согласуется с предсказанием ветви B⁺ (4.53 и 4.22, ошибка 2–10 %) и исключает альтернативную интерпретацию (знакочередование, скорости 5.50 и 5.04, ошибка 11–26 %). Этот тест сыграл решающую роль в определении, какая ветвь входит в закон при дробных d.

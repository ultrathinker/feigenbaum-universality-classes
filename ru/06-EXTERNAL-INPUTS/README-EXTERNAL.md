# 06-EXTERNAL-INPUTS — внешние входы для класса d = 2 (копии артефактов смежных проектов)

Класс d = 2 в статье опирается на результаты двух смежных (пока не опубликованных) проектов. Чтобы рукопись и пакет были самодостаточны, сюда скопированы **ровно те артефакты**, из которых берутся числа строки d = 2 (код, сертификаты, отчёты, JSON), с сохранением их внутренних имён. Ничего из них здесь не пересчитывалось заново; их статус строгости указан так, как он установлен в исходных проектах.

Замечания.
1. Статус «λ₂(2) сертифицирована до ±1.8·10⁻³³» в предыдущих версиях рукописи звучал без оговорки; правильная формулировка — «численно верифицировано: сертифицированное собственное значение коллокационной дискретизации N = 48; ошибка усечения оценена эвристически» — одинаково для d = 2, 4, 6.
2. Внутри скриптов этих папок пути были абсолютными (машина авторов); при сборке пакета они заменены на относительные там, где цель есть в пакете (см. `05-CODE/RELINK-LOG.md`); остальные оставлены и перечислены как внешние.
3. Полные тексты смежных проектов (статья d = 2 с приложениями и вся ферма промежуточных сертификатов, ~2400 файлов) в пакет не включены — только артефакты, от которых зависят числа этой рукописи.
